## Context

FIL-11 stages whether the filter's age posterior moves off the prior. Two cheaper questions of the
same size also gate whether the project has a result, and both are answerable from MOD-21's six
Abdella traces **before or alongside** the arrival generator — without waiting for a full simulator
or controller.

**Gate 0a — variance decomposition of arrival effective age.** Split Var(τ_arrival) into the part
from transit **duration** and the part from transit **temperature**. Under MOD-11=C this falls out
of the same Arrhenius integral that builds the arrival generator. It decides whether "transit
dominates effective age" (and the SCN-F2a pack-date claim) is true, and it feeds FIL-11 because
arrival spread is the only identification signal (MOD-02 / MOD-03 make in-store ageing constant and
known).

**Gate 0b — controller sensitivity / caseRound swallow check.** Given that arrival-age spread, how
far does the base-stock target move between the **true** age composition and the **prior-mean**
composition? X-12's body: if the gap is reliably smaller than one case, `caseRound` swallows it and
the headline VOI is zero by rounding. X-12=A deliberately installed **no tripwire**; Gate 0 does not
reopen that — it measures the cost of the conservative stack early, while cadence / case size /
action-space reversals are still cheap.

## Decision

We will adopt **A — Run both Gate 0 calculations** (variance decomposition of arrival effective age;
controller-sensitivity / caseRound swallow check) **before or alongside** building the arrival
generator and committing Gate 0 figures.

## Alternatives considered

- **B — Run the variance decomposition only** — rejected because 0b is the number that decides
  whether there is a headline VOI at all under case rounding.
- **C — Run the controller-sensitivity calculation only** — rejected because 0a decides the
  contrarian transit-dominance claim and FIL-11's identification story.
- **D — Skip — build the simulator and find out** — rejected because a reversal discovered after
  weeks of filter/controller work costs a rebuild; consistent with X-12=A's no-tripwire stance but
  too late for cheap parameter reversals.

## Consequences

- Gate 0 figures (`figures/m1/gate0_*.png`) are on the M1 critical path alongside Abdella fetch
  (T-003), not an optional appendix.
- Results inform MOD-25 / MOD-26 sensitivity framing and may flag X-11 / X-04 / case-size
  escalations before Wave 4 filter work.
- Does **not** reopen X-12=A; knowing early is not installing a tripwire.
- Cost: two focused calculations and figure commits before full sim; blocks if Abdella traces are
  unavailable (do not invent temperature paths).
