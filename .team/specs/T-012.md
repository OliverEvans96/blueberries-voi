# T-012 Stage C generative check

## Context

ADR 0088 redefines FIL-11 Stage C as generative agreement vs `day_step`, replacing the M1 soft-LL
TV self-check. This ticket makes that check runnable and falsifiable.

## Acceptance criteria

- [x] `run_fil11_stage_c` (or `run_m15_stage_c`) **fails** when an injected wrong-physics observation
      model is used (e.g. soft powers or hazard×dt deaths) while the simulator stays on shared
      `day_step` kernels — observable `passed=False` / non-zero divergence metric.
- [x] The same check **passes** under the production MC LL (T-011) within a documented tolerance
      (TV/KL on discrete masked obs, or paired CRN match rate), with `passed=True`.
- [x] M1 tautological soft-LL `tv_vs_exact` is not the production Stage C gate; dead code is removed
      or clearly marked non-gate.
- [x] Experiment entrypoint is runnable via documented `uv run`; writes a figure under
      `figures/m1.5/` and a short result MD (path documented in `figures/m1.5/README.md` or
      `experiments/`).
- [x] Optional auxiliary at small L/K: ResearchParticleFilter vs brute-force under the **same** MC/closed-form LL is
      reported if implemented; it must not restore soft-self-consistency as the pass rule.
- [x] Quality gates green.

## Out of scope

- Multi-rung Stage A/B publication (T-016 / T-017)
- Changing production LL (owned by T-011)
- Browser / CTL / VOI
