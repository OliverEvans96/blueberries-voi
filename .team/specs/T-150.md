# T-150 — f-native hierarchical arrival freshness model

Decision of record: **[ADR 0144](../adr/0144-f-native-hierarchical-arrival-model.md)**
(supersedes [0138](../adr/0138-arrival-f-birth-wiring.md) and
[0141](../adr/0141-unified-gamma-arrival-model.md)). Read it before writing tests or code — the
`k·θ·η_ref = 1` recalibration and the "no channel observes `f`" invariant are the two things
most likely to be violated by accident.

## Process

TDD is binding. **qa writes RED tests before any production code**, per phase, and records the
criterion → test map in **`.team/qa/T-150-tests.md`**. The verify verdict goes to
`.team/qa/T-150.md`. Implementation lands as **three commits, one per phase, in order**; never
mix a rename with a semantic change in the same commit.

Phase 1 is mechanical and must leave the suite green with **no edited numeric expectation**.
Phase 2 changes physics and is expected to move goldens. Phase 3 changes the wire, the frontend,
and the calibrated constants.

### Phase 2 — gamma unification, artifact, `arrival.rs`, truth path, filter path

- [ ] **AC2.1 — one gamma convention.** `GammaDecrementTable::for_params`
      (`physics.rs:275`) constructs `Self::new(params.gamma_shape * factor, params.gamma_scale)`.
      `gamma_decrement_scale` is **deleted**; if any caller still needs it the switch is
      incomplete. `draw_gamma_decrement`, `gamma_decrement_cdf` and
      `gamma_decrement_interval_prob` scale shape, not scale.
- [ ] **AC2.2 — additivity.** Aging through `Λ₁` then `Λ₂` matches aging through `Λ₁ + Λ₂` in
      distribution (mean and variance to tolerance), and halving the shelf timestep leaves
      accumulated mean and variance unchanged. Both are asserted directly, not inferred.
- [ ] **AC2.3 — shape-scaling spread.** At `t_store_c = 4`, `q10 = 3`, `t_ref_c = 0` the daily
      decrement has `sd = θ√(kφ)`, not `θφ√k`. At the *pre-recalibration* parameters
      (`k = 2`, `θ = 0.08`) that is 0.141 rather than 0.176 with the mean unchanged at 0.248 —
      a fixture qa may use to isolate the convention change from the recalibration.
- [ ] **AC2.4 — single reference life.** `ModelParams::default()` satisfies
      `gamma_shape · gamma_scale · eta_ref == 1` to `1e-12`, i.e. `gamma_scale = 1/28`
      (was 0.08). A single derivation choke point (`set_reference_life` or equivalent) is the
      only place `gamma_scale` is derived from `eta_ref`; `apply_rpc_configure` calls it when
      `eta_ref` is supplied without an explicit `gamma_scale`, and an explicit `gamma_scale`

- [ ] **AC2.5 — transit/shelf scale sanity.** A 2-day transit at 1 °C costs the same freshness
      as 2 shelf-days at 1 °C, and the ratio to 2 shelf-days at 4 °C is `3^0.1 / 3^0.4`. Under
      the recalibrated parameters the 2-day 1 °C cost is `2 · 3^0.1 / 14 ≈ 0.159`; qa asserts
      the *relationship*, and pins the number from the committed parameters rather than from
      this document.
- [ ] **AC2.6 — artifact.** `data/abdella/arrival_model.json` exists, is hand-authored with

## Interfaces

Generative model (ADR 0144 §3), all in f-space:

```
d       = d_min + Gamma(a_d, b_d)              per corridor, from arrival_product
T_bar   ~ TruncNormal(mu_T, sigma_T, low=0C)
phi_bar = q10^((T_bar - T_ref)/10)
psi_pos ~ Lognormal(0, sigma_pos)              PER UNIT
Lambda  = d * phi_bar * psi_pos                cumulative thermal exposure, reference-days
D       ~ Gamma(k * Lambda, theta)             PER UNIT
f       = max(0, 1 - D)

P(f > x | Lambda) = gamma_p(k*Lambda, (1 - x) / theta)
P(f = 0 | Lambda) = gamma_q(k*Lambda, 1 / theta)      exact, never grid mass
```

Recalibrated parameters (`crates/voi_core/src/params.rs`):

```
gamma_shape k = 2.0            unchanged
eta_ref       = 14.0           reference shelf life, days at T_ref = 0 C
gamma_scale θ = 1/(k*eta_ref) = 1/28 ~= 0.035714     was 0.08
invariant:      k * theta * eta_ref == 1
```

New / changed Rust surface:

- `crates/voi_core/src/arrival.rs` — artifact parse, `ArrivalModel`, per-rung
  `p(f | observation)` builder, one embed accessor.
- `physics.rs` — `GammaDecrementTable::for_params` scales shape; `gamma_decrement_scale` deleted.
- `params.rs` — reference-life derivation choke point.
- `day_step.rs` — delivery block draws from `ArrivalModel`; `UnitDayStepIn.age_at_receipt` gone.
- `unit_pf.rs` — `resolve_arrival_lambda` → channel-conditional law resolution.
- `session.rs` — `arrival_product` honored; arrival summary on the snapshot wire.
- `shipments.rs` — superseded helpers removed (AC2.15).

Artifact: `data/abdella/arrival_model.json` (schema-versioned) + `data/abdella/PROVENANCE.md`
section + `scripts/arrival_calibration_note.py` → `calibration_note.md` + one overlay figure.

Conditional structure the artifact must support:

| Rung | Conditions on | Integrates over |
| --- | --- | --- |
| F3 | `T_bar` (hence `φ̄`) | `d` if unobserved, `ψ_pos`, gamma |
| F2 / F2a | `d` only | `T_bar`, `ψ_pos`, gamma |
| P0 / P1 | nothing | `d`, `T_bar`, `ψ_pos`, gamma |

## Implementation constraints

These are binding on the implementer; a reviewer should reject a diff that violates them.

- **Cache shape follows what the rung observes.** Mirror `GammaDecrementTable`
  (`physics.rs:262-301`): fixed 4096-point grid, linear interpolation, built once via a
  `for_params`-style constructor. One table does **not** fit all rungs. P0/P1: the mixture over
  `d` and `T_bar` is fully collapsible, so pre-mix **one** 1D CDF over `f`, built once.
  F2/F2a: `pack_date_days` is `Option<i32>` (`obs.rs:58`), so cache a small map keyed by that
  integer — cheap and exact. F3: `T_bar` is continuous, so pre-mixing is impossible; keep a
  table over the `Λ` quadrature nodes and interpolate.
- **RNG streams: add new names, never repurpose old ones.** `SpawnRng::spawn_rng` addresses
  streams by hashing the stream name (`spawn_rng.rs:23-31`), so adding a stream costs nothing
  and perturbs nothing. Give each new quantity its own stream (`:arrival_duration`,
  `:arrival_temp`, `:arrival_pos`, `:arrival_gamma`) and **retire** `ARRIVAL_SHIP` /
  `ARRIVAL_SENSOR` rather than redefining what they draw, so review can see exactly which
  goldens are expected to move. Demand / spoil / alloc goldens must stay bit-identical.
- **Do not introduce a third RNG addressing scheme.** Two already exist: string-named
  `SpawnRng` (`rollout.rs:14-18`, `alpha_tune.rs:19`) and numeric `stream_rng`
  (`session.rs:27`, `voi.rs:23-30`). Add the new streams consistently to both; add no third.
- **`ψ_pos` and the gamma draw are per unit, not per delivery.** Drawing them per delivery
  reproduces the exact bug being fixed.
- **Embed the artifact exactly once.** `demand_profile.json` is `include_str!`'d at six-plus
  sites (`params.rs:75`, `demand_profile.rs:121`, `alpha_tune.rs:456`, `physics.rs:658,690`,
  `voi.rs:548`, `session.rs:815`). Do not replicate that pattern.
- **Quadrature nodes and weights are deterministic and version-pinned in the artifact**, or
  Python/Rust parity drifts for reasons unrelated to the model.
- **No new runtime dependencies.**

## Risks the next roles should know

1. **The "14×" is branch-dependent.** The `eta_ref` division makes transit 14× too cheap on the
   pack-date and temperature-history branches, but the P0/P1 default branch reconstructs
   `delivery_lambda` by dividing by `k·θ = 0.16` first (`day_step.rs:270-276`), so it nets out at
   ≈2.24× too cheap. Do not write a test asserting a uniform 14× correction across all rungs.
2. **The recalibration and the convention switch move numbers together.** Isolate them: AC2.3
   pins the shape-scaling spread at the *old* parameters, AC2.4 pins the new parameters. Landing
   them in one commit without that separation makes every golden move for two reasons at once
   and makes the diff unreviewable.
3. **Three review rounds is the escalation limit.** Phase boundaries are the mitigation. If
   Phase 2 alone exceeds one failed round, stop and split it rather than pushing through.
4. **Phase 3's recalibration is the long pole**, not the code. α tuning, VOI CRN and two
   notebooks all regenerate. Budget for it, and do not let a stale committed α table pass as
   "unchanged".
