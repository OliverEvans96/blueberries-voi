# T-046 Slim wheel build + GitHub Release + micropip smoke

## Context

Production interactive path installs the library inside Pyodide via micropip from a GitHub
Release URL. Depends on T-044 extras / derived product (merge Wave 1 tip; parallel with T-045).

## Acceptance criteria

- [ ] CI (or documented release workflow) builds a **slim / browser-oriented wheel** that installs
      without requiring pyarrow or matplotlib at runtime for the interactive import graph.
- [ ] Workflow publishes (or dry-run uploads in PR) artifacts to **GitHub Release** assets; docs
      state the Release URL pattern for `micropip.install` (not PyPI).
- [ ] Pin **Pyodide 314.0.4** / **CPython 3.14.2** is recorded in ADR 0099 (already) and in
      packaging docs / workflow comments or env vars used by the build.
- [ ] GitHub Actions CI matrix includes **Python 3.14** alongside 3.11 and 3.12 for native
      package tests (or a dedicated job that at least installs and imports the slim path).
- [ ] A smoke step (CI job or script) demonstrates the wheel metadata / install graph is free of
      hard deps on `pyarrow` and `matplotlib` for the browser extra.
- [ ] Derived Abdella artifact needed for browser demos is included in the Release assets or
      inside the wheel package data and loadable without parquet.

## Out of scope

- Full in-browser Pyodide worker RPC (T-047)
- Implementing ASGI (T-050)
- Publishing to PyPI

## Interfaces

```text
# Documented for consumers
micropip.install("<github-release-wheel-url>")
# Package data / asset: derived Abdella product path constant
```
