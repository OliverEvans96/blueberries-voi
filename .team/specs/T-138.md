# T-138 Stage A — heterogeneous arrivals (within-lot birth dispersion)

## Context

ADR 0137 showed that lot-uniform birth makes GSIN spoilage intervals never strictly tighter
than the pooled store interval, so `waste_by` cannot sharpen the shared-decrement posterior.
Stage A adds aleatoric within-lot freshness spread on truth and filter, wires a dedicated
`:birth` CRN stream, and fixes rollout belief initialization — without changing the ADR 0137
likelihood primitives.

## Acceptance criteria

### Params and shipments (AC-1–AC-3)

- [ ] **AC-1:** `ModelParams` exposes `arrival_dispersion_sd: f64` with default `0.0`, distinct
  field from `f2a_transit_uncertainty_sd`; a unit test asserts both fields exist and defaults
  differ in name and semantics (setting one does not mutate the other).
- [ ] **AC-2:** `shipments::birth_f_units(mean_f, sd, n, rng) -> Vec<f64>` returns length `n`,
  each value in `(0, 1]`, with `sd = 0.0` yielding `n` copies of `mean_f` (within `1e-12`).
- [ ] **AC-3:** With `sd > 0` and `n ≥ 8`, at least one draw across 100 seeds has
  `max(values) - min(values) > 1e-6` while the sample mean stays within `3 * sd` of
  `mean_f` (truncation-aware).

### Truth day step (AC-4)

- [ ] **AC-4:** On delivery, `unit_day_step` extends the new lot segment with
  `birth_f_units(...)` (per-unit vector) instead of `vec![birth_f; total_units]`; a test with
  fixed `:birth` CRN and `arrival_dispersion_sd > 0` shows at least two distinct freshness
  values in the appended segment.

### Filter birth (AC-5–AC-6)

- [ ] **AC-5:** `filter_step_unit` draws one lot-mean `birth_f` per particle (existing
  epistemic paths unchanged), then spreads to `obs.arrivals` units via `birth_f_units` using
  `params.arrival_dispersion_sd`; `push_lot` receives per-particle birth vectors whose length
  equals `obs.arrivals`.
- [ ] **AC-6:** With `arrival_dispersion_sd > 0`, two particles in the same step can hold
  different within-lot freshness patterns while sharing the same lot segment width (observable
  via bank row slice inequality after birth).

### STREAM_BIRTH CRN (AC-7–AC-8)

- [ ] **AC-7:** Rust production paths (`session.rs`, `voi.rs`, `rollout.rs`, `alpha_tune.rs`)
  and Python `rng.py` define `STREAM_BIRTH` / `:birth`; within-lot dispersion draws use only
  this stream, not `:arrival_ship` or `:arrival_sensor`.
- [ ] **AC-8:** `tests/test_rng.py` (or equivalent) asserts `:birth` is in `KNOWN_STREAMS`,
  is independent of `:arrival_ship` on the same `(root_seed, run_id, day)`, and matches Rust
  `SpawnRng::spawn_rng(..., ":birth")` bit parity on a shared fixture (at least one u64 draw).

### Rollout belief init (AC-9)

- [ ] **AC-9:** `rollout::unit_state_from_f_belief` initializes live units by sampling from
  each lot's `f_marginals` over `f_grid` (one draw per unit under `:birth`), not
  `repeat_n(e_f, n)`; with a non-degenerate marginal and fixed seed, two units in the same lot
  can differ while both remain in `(0, 1]`.

### GSIN interval converse + sd=0 limit (AC-10–AC-11)

- [ ] **AC-10:** Replace `gsin_waste_never_narrows_the_pooled_interval` with
  `gsin_waste_can_strictly_narrow_under_within_lot_dispersion`: over ≥5_000 randomized
  cohort-consistent shelves with within-lot freshness jitter (simulating `sd > 0`), at least one
  case yields `Some(I_gsin)` strictly tighter than `Some(I_pooled)` (proper subset, non-empty).
- [ ] **AC-11:** With lot-uniform freshness (simulated `sd = 0`), the same test recovers the
  ADR 0137 outcome: `I_gsin` equals `I_pooled` or is empty — never a strictly tighter
  non-empty proper subset.

### Conservation and likelihood guards (AC-12–AC-13)

- [ ] **AC-12:** `gsin_upc_diag` homogeneous-fleet regime reports `count_bias` with
  `|mean_bias| ≤ 0.05` per scenario row (same seeds/horizon as today); dispersion must not
  reintroduce systematic alive-count drift.
- [ ] **AC-13:** Shared-decrement likelihood unchanged — `unit_pf_ac` guards still pass:
  `superseded_binomial_waste_primitives_are_gone`,
  `production_likelihood_terms_take_no_rng`, and `delta_interval_loglik` remains the spoilage
  scorer (no `binom_pmf` / per-unit spoil in production `unit_pf`).

### Diagnostic dispersion sweep (AC-14)

- [ ] **AC-14:** `gsin_upc_diag` adds a **"Dispersion sweep"** regime that runs the
  heterogeneous-fleet overlapping-lots fixture at `arrival_dispersion_sd ∈ {0.0, 0.05, 0.10}`
  (three JSON rows per scenario channel); `experiments/regen_gsin_upc_data.sh` regenerates
  output including the new regime rows.

### Guard supersession (AC-15)

- [ ] **AC-15:** No test or guard reinstates lot-uniform-only birth as the sole path when
  `arrival_dispersion_sd > 0`; qa updates `unit_pf_ac.rs` in this ticket (named above) before
  implement lands.

## Out of scope

- Changing cross-lot sales allocation, contrast weighting, or spoilage likelihood form (Stage
  B — T-139).
- Multi-lot-per-delivery / MOD-16 option A (Stage C — T-140).
- Studio UI slider for `arrival_dispersion_sd` (Rust params + diag only in this ticket).
- Overloading `f2a_transit_uncertainty_sd` as within-lot spread.
- Web shipment JSON on every init (unchanged from ADR 0138).

**Behavioural contracts:**

| Path | Lot mean (epistemic) | Within-lot spread (aleatoric) |
|------|----------------------|-------------------------------|
| Truth `unit_day_step` | `delivery_birth_f` / wired `delivery_f` | `birth_f_units` via `:birth` |
| Filter `birth_f` + birth block | existing `birth_f(obs, …)` | `birth_f_units` per particle via `:birth` |
| Rollout init | marginal over `f_grid` | per-unit sample via `:birth` |

**Tests superseded:** `gsin_waste_never_narrows_the_pooled_interval` → AC-10/AC-11 pair in
`crates/voi_core/tests/unit_pf_ac.rs`.
