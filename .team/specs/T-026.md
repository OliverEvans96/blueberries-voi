# T-026 caseRound + constant-order policy

## Context

CTL-01 and the ladder floor need case-size rounding and a constant-\(q\) policy primitive in a pure
`controller/` module (X-04: order quantity only).

## Acceptance criteria

- [ ] `case_round(x, case_size)` returns an int multiple of `case_size` with documented rounding mode
      (fixture table: several `x` → expected multiples; default `case_size=8` matches `ModelParams`).
- [ ] A `ConstantOrderPolicy` (or equivalent) implements the T-024 `Policy` protocol and always
      returns a fixed case-rounded quantity.
- [ ] `controller/` modules introduced here do **not** import matplotlib, pyarrow, or write files.
- [ ] Package export surface lists the new symbols (non-empty `__all__` update as appropriate).
- [ ] `uv run pytest` for this ticket’s tests passes.

## Out of scope

- Survival-weighted or Rung 0 policies (T-027/T-028)
- Profit accounting (T-025)
- Browser / Pyodide façade

## Interfaces
