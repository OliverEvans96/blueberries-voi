# T-039 VOI sweep orchestrator (scenario × β)

## Context

X-06 / VOI-04 require a fine (scenario × β) surface. This ticket wires metric + CRN cell + bootstrap
into a sweep API with production defaults and smoke overrides (ADR 0095).

## Acceptance criteria

- [x] `voi.sweep` (or export) runs a grid over ADR 0096 scenarios × a β list and returns, per
      `(scenario, beta)` with scenario ≠ P0: absolute VOI, pct VOI, and paired bootstrap CI fields.
- [x] Production default β grid has **≥10** distinct values and **includes 1.0**.
- [x] Smoke / CI entrypoint uses a tiny budget (ADR 0095) but still includes β=1 and ≥1 β>1.
- [x] P0 profits are retained internally as the denominator; VOI columns follow ADR 0096.
- [x] Result object / mapping is JSON-friendly (lists/floats/dicts; no numpy types required at the
      boundary — convert on export).
- [x] Unit/integration tests call smoke budgets only.

## Out of scope

- Writing experiment markdown / figures (T-040)
- Honesty arms (VOI-02=A)
