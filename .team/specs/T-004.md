# T-004 Arrival generator, forward simulator, SIM-04 logging

## Context

With shared kernels and Abdella traces available, M1 needs a forward world that produces multi-cohort
state, P1 observations, and per-lot ground truth for filter validation — driven by an open-loop
age-blind base-stock (S=60), not the M2 controller.

## Acceptance criteria

- [ ] Arrival generator bootstraps **all six** Abdella shipments, samples a temperature path, integrates
      Arrhenius/Q10 to arrival effective age, and applies left-truncation per MOD-06.
- [ ] A diagnostic knob can **tighten** arrival-age spread without forking a second code path (for
      FIL-11 stage A contrast).
- [ ] Forward simulator uses shared `model.day_step` only (no duplicated transition).
- [ ] Open-loop driver uses age-blind base-stock **S=60**, LT=1, daily delivery as **one lot** per
      delivery (MOD-16); orders `max(0, S - on_hand)` with delivery accounting documented in tests.
- [ ] SIM-04 logging records every day, for every live lot: `(n_ℓ, τ_ℓ)`, plus aggregates needed for
      P1 (sales total, waste total, exact arrival counts) and live cohort count L.
- [ ] P1 observations for M1: daily sales total, waste total (no lag), exact arrival counts; no lot
      IDs at POS/shrink; perfect shrink reporting (compliance=1) unless a test explicitly toggles
      otherwise.
- [ ] Smoke test: after burn-in + scored horizon (e.g. 90 scored days), inventory and waste are
      finite; L distribution (p50/p90/max) is recorded to a testable artifact.
- [ ] Cohort-count-over-time figure is written to `figures/m1/cohort_count.png` (or equivalent) via
      a documented `uv run` entrypoint.
- [ ] Extinction follows FIL-14=A (`n=0` only); L diagnostic uses that rule.

## Out of scope

- Production RBPF (T-006)
- FIL-13 bakeoff backends (T-005)
- Survival-weighted / damped base-stock controller (CTL-01 — M2)
- Shrink noncompliance κ < 1 as default
