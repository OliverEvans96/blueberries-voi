# T-081 CAL-A3 — Day-indexed controllers

## Context

ADR 0109/0011 mandatory re-derive #1–2: protection and age-blind weights become day-indexed under
MWF cadence. May land with day-varying protection **length** and homogeneous μ before T-082
heterogeneous μ (ADR 0113).

## Acceptance criteria

- [ ] `damped_sw` (and related SW helpers) use `OrderSchedule.protection_days(day)` (or injected
      callable) instead of scalar `PROTECTION_DEMAND_DAYS=2` for base-stock / quantile inputs on
      order days.
- [ ] On Sun/Tue/Thu order days under the default schedule, protection lengths used by the
      controller are 3 / 3 / 4 respectively (unit or integration test).
- [ ] Rung 0 / corrected age-blind survival weight is **day-indexed** (periodic), not a single
      scalar that silently assumes daily stationarity; a test fails if a scalar-only path remains as
      the production default under CAL-01 schedule.
- [ ] α-tuning inputs (`alpha_tune` / related) accept or compute day-indexed protection coverage;
      documented so T-083 can retune gates.
- [ ] If heterogeneous daily μ is not yet available, protection may treat NB as homogeneous with
      day-varying length only; code path is documented for T-084 / B4 upgrade.
- [ ] Controllers do not place conceptual orders on non-order days (consistent with T-079 gate).
- [ ] Focused tests cover at least SW protection 3/3/4 and Rung0 day-index smoke; ruff/mypy on
      touched paths pass.
