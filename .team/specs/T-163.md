## Stage 1 — Transit generative v2

*Source: `arrival-transit-generative-v2.md` §0–§6.*

### Acceptance criteria

- [ ] **S1.1 — Abdella duration marginal.** Simulated total transit `d` from bottom-up stage draws has the same law as `d_min + Gamma(a, b)` for committed `abdella_all` fit `(d_min, a, b) ≈ (1.853, 3.009, 0.974)` (v2 §1.2, §3.4.1, §6 checklist). *Check:* analytic or MC test on `Σ_k d_k`.
- [ ] **S1.2 — Var(log d).** At `ρ = 0`, `Var(log d)` from the generative model is within **±0.02** of observed **0.205** (v2 §3.4.3; handoff calibration resolution).
- [ ] **S1.3 — Clean-chain φ̄ moments.** At `ρ = 0`, simulated mean and SD of `φ̄` (and mean `Λ`) are within agreed tolerances of the six Abdella shipments (~mean 1.36, SD ~0.07–0.08 in φ-space) after tuning nominal `μ_k` / mode offsets / `σ_hour` (v2 §3.2, §3.4.2).
- [ ] **S1.4 — Hourly OU on path.** At `ρ = 0`, delivery-temperature traces are **not** piecewise-constant flat steps — hourly OU wiggle is visible (v2 §1.4, §3.4.6, §6 checklist).
- [ ] **S1.5 — Break pulses.** At default `ρ > 0`, some generated traces reach `T_break` within trip duration (v2 §1.5, §6 checklist). Break exposure remains exactly additive: `Λ = d·φ_set + Σ ε_j` (ADR 0150 §1).
- [ ] **S1.6 — Trace ↔ integrator parity.** For ≥40 seeded draws, `resolve_arrival_exposure(trace)` matches reported `Λ` within trapezoid tolerance (v2 §1.6, §6 checklist).
- [ ] **S1.7 — Filter coherence.** Monte Carlo generative `Λ | d` (or `f | d`) mean/variance matches filter `Duration(d)` law within tolerance at `ρ = 0` and at default `ρ` (v2 §2.6, §3.4.7).
- [ ] **S1.8 — Ladder ordering.** `ac2_11a_empirical_ladder_tracking_mae` keeps **strict** MAE ordering richest → least-informed; `MAE(P0)/MAE(F2) ≥ 3.0` at `n ≥ 64` — never relax (v2 §3.4.5; handoff verification targets).
- [ ] **S1.9 — Artifact schema.** `data/abdella/arrival_model.json` has `legs`, trip-mode fields, `sigma_hour`, `T_break`, `rho`, `tau_bar`; **no** `mu_T`, `sigma_T`, or `temp_floor_c` (v2 §4.1, §6 checklist).
- [ ] **S1.10 — Fit script honesty.** `scripts/fit_abdella_arrival.py` fits duration gammas only; documents assumed modes, `σ_hour`, and break parameters in provenance / `calibration_note.md`; does not fit truncated-normal temperature (v2 §3, §3.4; ADR 0148 amendment).
- [ ] **S1.11 — Unified corridor.** Studio does not expose `short_haul` / `long_haul` as first-class arrival chips; default session uses one `abdella_all` family (v2 §1.2, §4.3).
- [ ] **S1.12 — Per-day runtime.** `cargo run -p voi_core --release --bin bench_day_timing` reports per-day cost within noise of baseline **~5.7 ms/day @ N=200** (v2 §0, §4.2, §6 checklist; handoff).
- [ ] **S1.13 — Design variance share.** `scripts/arrival_calibration_note.py` (or equivalent) reports duration vs break share of `Var(log Λ)` at default `ρ` as a **design** metric (~80% duration target acceptable; not fit from six traces) (v2 §3.4.4; handoff).
- [ ] **S1.14 — Breaks inside calendar d.** Total trip duration `d` is calendar time; breaks are periods **within** `d`, not additive extensions (v2 §1.5 inferential lock; handoff).
- [ ] **S1.15 — UPC mixture law (Stage 1 API).** `ArrivalModel::mixture_law` remains correct: mean averages components, variance exceeds average component variance (ADR 0149 / existing `t151` tests; needed before Stage 2 UPC birth).
- [ ] **S1.16 — Guard supersession (t151).** Tests encoding the **withdrawn** deterministic-baseline assumptions are updated in this ticket before implement:
  - `t151_cold_chain_breaks::zero_break_rate_makes_exposure_a_function_of_duration_only` — **delete or replace** (at `ρ = 0`, modes + OU still vary `φ̄`).
  - `t151_cold_chain_breaks::break_free_trip_has_deterministic_exposure` — **replace** with v2 break-free baseline semantics (stage gammas + mode + OU, not fixed `d·φ_set` scalar).

## Stage 2 — Multi-lot deliveries (L = 3)

*Source: `arrival-breaks-multilot.md` §2–§3; handoff Stage 2.*

**Prerequisite:** all Stage 1 criteria green.

### Acceptance criteria

- [ ] **S2.1 — Three lot ids.** `session.rs::advance_one` mints **L = 3** lot ids per delivery and populates `RichDay.arrival_lot_ids` (length 3) (multilot §2; handoff).
- [ ] **S2.2 — Exposure additivity per lot.** Each lot `ℓ` has `Λ_ℓ = Λ_upstream,ℓ + Λ_shared` with one shared DC→store leg per delivery (multilot §2).
- [ ] **S2.3 — Per-lot traces.** Truth path emits **three** splined traces (diverging upstream, shared tail); Events data carries per-lot trace list (multilot §2; handoff).
- [ ] **S2.4 — Quantity split.** Delivery quantity is **split** across lots (not multiplied); total units per delivery unchanged (multilot §2; handoff).
- [ ] **S2.5 — GSIN birth.** Under GSIN, `unit_pf.rs` pushes **three** shelf segments, each from its own `ArrivalCondition` (`Duration(d_ℓ)` or `Exposure(Λ_ℓ)`) (multilot §3; handoff).
- [ ] **S2.6 — UPC mixture birth.** Under UPC, one merged cohort of `Q` units is born from `Law_UPC = (1/L) Σ_ℓ Law_ℓ` (pointwise CDF average; mixture variance ≠ average of component variances) (multilot §3; handoff).
- [ ] **S2.7 — Per-lot resolve.** `resolve_arrival_f_law` is per-lot, not per-delivery (handoff).
- [ ] **S2.8 — FilterObs shape.** `FilterObs` carries per-lot pack dates and per-lot temperature traces; **no** new mask field; **no** `delivery_history_by_lot` (multilot §3; handoff).
- [ ] **S2.9 — unit_ll unchanged.** `unit_ll.rs` requires no semantic change; existing `n_lots` loops suffice (handoff).
- [ ] **S2.10 — Kernel tests green.** `cargo test -p voi_core -p voi_wasm` passes with updates to `t140_arrival_gamma`, `t141_*`, `t150_phase2_arrival_model`, `t_events_temp_trace`, `unit_pf_ac` as needed (multilot verification §1; handoff).
