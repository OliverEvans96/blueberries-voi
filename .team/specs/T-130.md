# T-130 Studio layout v5 round 3 (user feedback)

## Context

T-127 delivered the Cockpit Grid with a Run sidebar (DecisionRail + Today strip). User
feedback and T-128 planning identified dead whitespace, duplicated obs controls, and charts
buried in the tuning dock. Round 3 consolidates run controls into Secondary, centers Today
metrics, gives Events a full-height column, and tightens chart/control polish.

## Acceptance criteria

### Layout v5 grid

- [ ] `cockpitGrid.css` defines a 3-column grid with areas `economics | today | events` on
      the middle row and `tuning | tuning | events` on the bottom row; Events spans all three
      rows (`grid-row: 1 / span 3`). `npm test` — `StudioLayout.test.ts` asserts
      `economics today events` in `cockpitGrid.css` and `data-layout="v5"` on `.cockpit-grid`.
- [ ] `StudioLayout.tsx` retires `#decision-rail-host` and `.cockpit-pane--run`; Today is
      `.cockpit-pane--today` with inventory, controller orders, and age-comp charts visible;
      `#chart-sales` and `#chart-stockout` remain in the DOM but hidden (`.visually-hidden`).
- [ ] Secondary pane order: `#chart-belief-lg` histogram → `#secondary-chrome-host` (obs,
      truth, tradeoff tabs) → `#operator-bar-host` at the bottom. Test asserts chrome host
      precedes operator bar and operator bar is last child.
- [ ] Tuning dock occupies the left two columns at full width (no Run sidebar). Demand
      section colocates `#chart-demand` inline via `#chart-demand-host` inside the demand
      controls block (not only in hidden registry).

### Secondary chrome & tradeoff reactivity

- [ ] `SecondaryChrome.tsx` mounts obs scenario chips (`data-obs`), truth toggle, and a
      Curve|Histogram tab strip; only one tradeoff host visible at a time. Switching tabs
      re-renders the active chart via `useEffect` (not stale ref callbacks).
- [ ] `SecondaryChrome.tradeoff.test.ts`: order-qty change updates curve/histogram SVG
      content; tab switch shows histogram rects after Curve tab showed paths.

### Charts

- [ ] `controllerOrders.ts` renders vertical bars (not a line) for order quantities.
      `controllerOrders.test.ts` asserts `rect` elements dominate the SVG.
- [ ] `pnlTimeseries.ts` draws lines only — no dot/circle markers on cumulative PnL.
      `pnlTimeseries.test.ts` asserts zero `circle` elements.
- [ ] `freshnessHistogram.ts` uses a single fill color for belief bars (aggregated mode);
      `freshnessHistogram.test.ts` asserts one distinct bar fill class/color.

### Tuning controls

- [ ] Observation physics slider label shows **1/σ** (inverse sigma), not raw σ.
      `controls.test.ts` or `paramLabels.ts` contract.
- [ ] Autopilot α/ρ drag pad has distinct styling (`#alpha-rho-pad` or
      `[data-testid='alpha-rho-pad']`); rollout policy defaults to the rollout option in
      `controls.ts`.
- [ ] `tuningDock.css` imported; demand controls and inline demand chart share one visual
      cluster (no duplicate hidden plot-age-comp in tuning when age-comp is on Today).

### Events pane

- [ ] `EventsPane.tsx` renders protection-interval days as a daily log (weekday heading,
      POS/waste/delivery rows). Lot breakdown strings omit zero-quantity lots.
      `EventsPane.test.ts` asserts filtered breakdown and daily log structure.

### Studio wiring & e2e

- [ ] `studioLogic.ts` mounts `SecondaryChrome` into `#secondary-chrome-host`, removes
      `DecisionRail` mount; wires hidden sales/stockout chart elements for hover link.
- [ ] `web/tests/studio-visual-qa.spec.ts` uses `.secondary-chrome [data-obs]` selectors
      (not DecisionRail); tradeoff assertions target `#tradeoff-curve-host` /
      `#tradeoff-histogram-host` inside Secondary; secondary test expects chrome + histogram.
- [ ] `cd web && npm test && npm run build && npm run e2e` all pass on Python 3.11 host
      (web-only ticket).
