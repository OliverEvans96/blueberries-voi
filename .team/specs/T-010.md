# T-010 RichObs + UNOBSERVED + scenario masks

## Context

FIL-08=C and ADR 0086 require one richest observation schema with per-rung masks. Missing fields
must not become zeros. This ticket introduces `RichObs`, `UNOBSERVED`, and masks for the M2.5
data-availability set without yet changing the likelihood.

## Acceptance criteria

- [x] `RichObs` is a frozen dataclass (or equivalent immutable type) exposing at least:
      `arrivals`, `sales_total`, `waste_total`, `sales_by_lot`, `waste_by_lot`,
      `pack_date` (or `asn_age_hint`), `age_at_receipt`, `lot_ids_live`.
- [x] A public sentinel **`UNOBSERVED`** is distinct from `0`, `None` used as “no delivery”, and
      empty mappings; type checkers / runtime can distinguish observed zeros from unobserved.
- [x] `ObsMask.apply(rich: RichObs) -> RichObs` sets absent fields to `UNOBSERVED` and never to `0`
      or `{}` for fields the mask hides.
- [x] `mask_for(scenario)` (or equivalent) covers **P0, P1, F1, F1s, F2a, F2** per ADR 0086 table;
      P0 hides `waste_total` while P1 presents it; both present `arrivals` and `sales_total`.
- [x] Unit test: building a full RichObs with `waste_total=0`, applying P0 mask, then reading the
      masked obs yields `UNOBSERVED` for waste — not `0`.
- [x] Round-trip helper: `rich_obs_from_day_log(day: DayLog, mask: ObsMask) -> RichObs` projects
      T-009 logs through a mask without inventing values for hidden fields.
- [x] Production `RBPF.step` accepts `RichObs` (or a documented adapter from `P1Obs` → `RichObs`
      with P1 mask); soft LL may still be temporary until T-011, but the type boundary is RichObs.
- [x] SCN-B-state is **not** implemented as a mask that fabricates observations (document skip /
      bypass hook only if touched).
- [x] Quality gates green (`ruff`, `mypy`, `pytest` ≥80% coverage).

## Out of scope

- Honest MC likelihood (T-011)
- F2a/F2 prior injection behaviour beyond schema fields (T-013)
- Lot-resolved LL terms beyond storing fields (T-014)
- Biased F1 ρ &lt; 1
- New scenario rungs

## Interfaces

```python
# blueberries_voi.filter.types (indicative)

UNOBSERVED: Final[object]  # singleton sentinel

ScenarioId = Literal["P0", "P1", "F1", "F1s", "F2a", "F2"]

@dataclass(frozen=True)
class RichObs:
    arrivals: int | UnobservedT
    sales_total: int | UnobservedT
    waste_total: int | UnobservedT
    sales_by_lot: Mapping[int, int] | UnobservedT
    waste_by_lot: Mapping[int, int] | UnobservedT
    pack_date: date | UnobservedT
    age_at_receipt: float | UnobservedT
    lot_ids_live: frozenset[int] | UnobservedT

@dataclass(frozen=True)
class ObsMask:
    present: frozenset[str]
    def apply(self, rich: RichObs) -> RichObs: ...

def mask_for(scenario: ScenarioId) -> ObsMask: ...

def rich_obs_from_day_log(day: DayLog, mask: ObsMask) -> RichObs: ...

def is_unobserved(value: object) -> bool: ...
```
