# T-047 Pyodide worker RPC + browser budget smoke

## Context

Prod host runs Pyodide only in a worker, binds one `EngineSession`, and exchanges JSON (no deep
`toJs`, no main-thread PyProxy). Depends on Wave 2 tip (T-045 + T-046 artifacts).

## Acceptance criteria

- [ ] A worker script (in this repo under a documented path, or in the web mockup path if ENG-01
      host scaffolding lives there) loads Pyodide **314.0.4**, installs the Release/slim wheel,
      constructs one bound `EngineSession`, and answers RPC methods `init` / `step` / `step_n` /
      `reset` / `act`.
- [ ] RPC payloads are **JSON strings** or plain JSON-cloneable objects produced via Python
      `json.dumps` / structured clone — tests or smoke assert no nested PyProxy is posted to the
      main thread.
- [ ] Main-thread code under the smoke harness never calls `pyodide.runPython` for per-click
      physics; it only `postMessage`s to the worker.
- [ ] Browser demo budget preset runs at least `init` + one `step` + one `step_n` (≥2 orders)
      successfully in the smoke (CI headless or documented local script with pass/fail exit code).
- [ ] Smoke uses dialed budgets (≤ demo caps from T-043), not production `N=2000` full rollout.

## Out of scope

- Wiring D3 studio chrome (T-057)
- HttpAdapter (T-056)
- Changing export schema

## Interfaces

```text
# Worker RPC (illustrative)
request:  { "id": str, "method": "init"|"step"|"step_n"|"reset"|"act", "params": {...} }
response: { "id": str, "ok": true, "result": Snapshot|DayDelta|list[DayDelta] }
       |  { "id": str, "ok": false, "error": { "type": str, "message": str } }
```
