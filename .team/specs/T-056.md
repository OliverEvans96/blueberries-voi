# T-056 HttpAdapter → local API (dev)

## Context

Dev adapter calls the Slice-2 ASGI app with the same EngineAdapter surface. Depends on T-050 and
T-053.

## Acceptance criteria

- [ ] `HttpAdapter` implements `EngineAdapter` against the T-049 route table.
- [ ] Uses `fetch` (or project HTTP helper) with JSON bodies; parses Snapshot/DayDelta.
- [ ] Session create on construct/`init`; delete/reset behaviour documented.
- [ ] Contract test or mock-fetch test asserts request paths/bodies and that economics are not
      POSTed on `setEconomics` (economics stay in projector).
- [ ] Points at local base URL configurable via constructor / env.

## Out of scope

- Deployed cloud API
- Pyodide path

## Interfaces

```text
class HttpAdapter implements EngineAdapter {
  constructor(opts: { baseUrl: string })
}
```
