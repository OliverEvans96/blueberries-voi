# T-030 CTL-02/04 one-step rollout + salvage

## Context

CTL-02=B single-step rollout wraps the CTL-01 base policy; CTL-04=B sets H≈2× shelf life with
survival-weighted terminal salvage. CRN pairing is mandatory (ENG-04).

## Acceptance criteria

- [ ] Rollout evaluates candidate orders for one improvement step using forward sims of horizon **H**
      with terminal salvage \(V_T = m \sum w_{\mathrm{long}}(\tau) n\) documented in code/docs.
- [ ] Under paired CRN, mean scored profit of the rollout policy is **≥** the base SW policy on a
      fixed fixture seed set (improvement or tie; never systematically worse beyond documented
      numerical tolerance).
- [ ] Optional compute-budget arguments exist (`n_rollout_paths`, `H`, candidate set size, and/or
      particle/sample caps) with **full desktop defaults**; omitting them preserves production
      behaviour.
- [ ] Forward steps call the same `model.day_step` path as closed-loop eval (no shadow dynamics).
- [ ] Rollouts are **sequential** (no `multiprocessing` / process pools).
- [ ] A CRN desync detector test fails when streams are intentionally crossed and passes when
      addressing is correct (ENG-04 prep).
- [ ] `controller/` remains free of figure/FS writers.
- [ ] `uv run pytest` for this ticket’s tests passes.
