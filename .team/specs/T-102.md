# T-102 Behavior-frozen structure refactor (waves A–C)

## Context

Post-TDD green left fat modules and duplicated helpers. This milestone splits
internals behind re-export façades per ADR [0118](../adr/0118-behavior-frozen-module-splits.md)
without changing scores, freezes, or locked imports. Waves A→B→C from the
repo-refactor plan; existing suite + AST hygiene tests are the safety net (no
qa RED suite).

## Acceptance criteria

- [ ] **No `tests/` edits** on the integrate tip (`git diff` vs parent shows zero
      paths under `tests/`). Prefer façades so AST scanners need no path updates.
- [ ] **Façade imports preserved:** from a clean install of the tip,
      `from blueberries_voi.filter.backends import get_backend, observation_loglik_mc, _rbpf_update`
      succeeds; `blueberries_voi.filter.__all__` is unchanged vs parent tip for
      this milestone’s merge; locked `viz.m15` / `viz.fil11` runners and pinned
      privates (`_arrival_prior`, `_spread`, `_write_stage_b_md` as today) remain
      importable from their current modules.
- [ ] **`def _rbpf_update` stays in `filter/backends.py`:** AST load of
      `blueberries_voi.filter.backends.__file__` still finds a top-level
      `def _rbpf_update(` (implementation may live under `filter/particle/`;
      façade delegates). Related file-pinned markers
      (`_rbpf_update_end_marker`, `_SHARED_MC_KERNELS` / identity tricks) still
      satisfy existing scanners.
- [ ] **Wave A landed behind façades:**
      - `filter/backends.py` is a thin façade over `filter/particle/` modules
        (`state`, counts update impl, `mc_likelihood`, `bakeoff`, `microbench`
        or equivalent); production update semantics unchanged (exact WOR;
        ESS resample at `< 0.5 * N`; `counts_only` path).
      - `filter/age_likelihood` remains importable as today via package
        `__init__` re-exports (`sequential_wor`, exact, mean-field diag,
        survival/KL/TV/MI split as planned); production path still WOR;
        MF/joint remain importable diagnostics (ADR 0105).
      - Proven-dead symbols removed only when grep shows no importers
        (`_expected_waste_mu`, `_apply_lot_map_age_update`, unused
        `coerce_p1_obs` / `p1_obs_from_rich` if unused, trivial `_ess` alias);
        `l_fallback.py` name may stay; always-`counts_only` unchanged.
      - Fat `model/__init__.py` split into params/physics/day_step (or
        equivalent) with `__init__` re-exports; `_shared_day_step_symbol` /
        `_SHARED_MC_KERNELS` identity tricks still work.
- [ ] **Wave B helpers exist without semantic unification:**
      - Shared calendar / day-step call / types-log modules under `sim/` with
        `__init__` (and `episode`) re-exports; triple `inspect.signature(day_step)`
        shims replaced by direct `day_step(..., day=day)` where `day` is already
        accepted — no change to when `day=` is omitted.
      - Belief empty/oracle helpers take **explicit** τ grids; call sites keep
        their current grids (no single canonical grid).
      - One shared NB protection-quantile helper used by existing call sites;
        dual `Policy.order` signatures remain; `invoke_order` (or equivalent)
        centralizes dispatch without collapsing the public Protocol.
- [ ] **Wave C wires wrappers only:** closed-loop episode, open-loop
      `run_episode`, `simulator/day_driver.advance_day`, m2 multi-scenario, and
      `voi/crn` scenario episode keep **existing public signatures**; ceil
      rounding stays local to day_driver/open-loop where it is today; **no**
      silent addition of order gates / `day=` where currently absent; rollout
      and m15/fil11 peels leave public entrypoints + locked privates re-exported
      from the old module paths.
- [ ] **Numeric / hygiene freezes still hold** under the existing suite: production
      `_rbpf_update` exact WOR; no HF on installable graph; no matplotlib on
      closed-loop/api; controller hygiene bans on `RBPF._state` unchanged;
      production path still no `mean_field_update`; `BACKENDS` membership;
      `case_round` re-export from episode as today; `RBPF._state` layout
      (`.counts` / `.age_post` / `.weights`) remains pokeable for current tests.
- [ ] **Verify gate (Python 3.11, CI-identical argv)** PASS on the integrate tip
      after waves A–C merge; verdict in `.team/qa/T-102.md`:

      ```bash
      python -m pip install --upgrade pip
      ```

- [ ] **Backlog notes only (no code unify):** integrate/close-out appends to
      `.team/backlog.md` the deferred semantic items (VOI/m2 order-gate/`day=`
      gaps vs episode; ceil vs nearest rounding owners; unused `ess_fraction` vs
      hardcoded `0.5*n`; `sim` vs `simulator` naming debt). Changelog gains a
      plain-English “structure cleanup, behavior unchanged” entry when verified.

## Out of scope

- Editing any file under `tests/` (including AST scanners)
- Unifying ceil vs nearest case rounding
- Collapsing dual `Policy.order` signatures to one
- Wiring missing MWF `OrderSchedule` / `day=` into `voi/crn` or
  `sim/m2_multi_scenario` when that would change scores
- Renaming `sim/` ↔ `simulator/`
- Changing ESS gate, WOR weights, or production backend selection
- Frontend / `web/` UX audits
- Collapsing API pydantic models with `simulator.schema`
- New runtime dependencies
- Merging to `main` (human)
- Editing `.github/workflows/`
- qa writing new RED behavioral tests (existing suite is the oracle)
