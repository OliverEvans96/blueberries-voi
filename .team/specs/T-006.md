# T-006 Production RBPF after FIL-13 settled

## Context

FIL-01=A commits to a Rao–Blackwellised particle filter (sample counts, marginalise age). Production
implementation waits until Oliver settles FIL-13 from the T-005 bakeoff and FIL-15 numerics are
accepted. This ticket builds that production filter for P1 observations.

## Acceptance criteria

- [ ] Preconditions documented and checked: ADR 0082 / 0083 flipped to ACCEPTED (or superseded) with
      chosen tractability backend and production K/N/ESS; otherwise this ticket does not start.
- [ ] Production filter samples **counts** and maintains a discrete age posterior per the settled
      FIL-13 option; arrival age is not impoverished by resampling along a sampled age coordinate
      (RBPF invariant for the chosen design).
- [ ] Bootstrap proposal (FIL-10 as settled) + **P1 likelihood** using sales total, waste total, and
      exact arrival counts.
- [ ] Systematic resampling triggers on ESS &lt; threshold (default interim N/2 unless FIL-15 sets
      otherwise); resampling uses `:filter_resample` stream.
- [ ] Static parameters are treated as known (FIL-07=A); β fixed at 2.0 for M1.
- [ ] Filter imports the **identical** `model.day_step` as the simulator; a regression test fails if
      imports diverge.
- [ ] Survival-ratio death regression from T-002 still passes when invoked through the filter
      transition path.
- [ ] Loud memory guard: attempting a configuration with `K^L · N` above the documented budget
      raises a clear error (no silent OOM loop).
- [ ] Losing bakeoff backends are quarantined under `experiments/` or clearly non-default; production
      import path exposes only the settled backend.

## Out of scope

- FIL-11 contraction/calibration/exact experiments (T-007)
- Parameter inference inside the filter
- Multi-rung observation models beyond P1
- Controller integration
