# T-007 FIL-11 staged filter validation (A then B then C)

## Context

FIL-11=D requires staged proof that the filter works: contraction go/no-go first, then calibration,
then exact comparison. Stage A is a **hard stop** — if the posterior does not move under realistic
arrival spread, B/C and controller work do not proceed.

## Acceptance criteria

- [ ] **Stage A — Contraction:** experiment compares full Abdella arrival mix vs tightened
      `spread_scale`; plots posterior vs prior for a tracked cohort; commits
      `figures/m1/fil11_contraction.png`.
- [ ] Stage A **pass rule** is observable: visible contraction (e.g. posterior variance or HPD width
      strictly below prior by a documented margin) under full mix; weak/absent under tight spread.
- [ ] If Stage A fails, the pipeline **stops**: no Stage B/C implementation work; a documented
      negative result path exists (figure + note); exit is non-silent.
- [ ] **Stage B — Calibration** (only if A passed): R≥50 replications (or documented raise if noisy);
      empirical 90% credible-interval coverage of true age is within a documented band around 90%;
      rank histograms are produced; commits `figures/m1/fil11_calibration.png`.
- [ ] **Stage C — Exact comparison** (only if A passed): at L∈{2,3} and small K, TV (or max abs
      error) vs exact forward is below a documented tolerance (e.g. TV &lt; 0.05); commits
      `figures/m1/fil11_exact.png`.
- [ ] Entrypoints `experiments/fil11_a.py` (and b/c when unlocked) are runnable via documented
      `uv run`; `figures/m1/README.md` maps figures → FIL-11 / decision IDs.
- [ ] Degeneracy bug-catcher available: at β=1, age-aware vs age-blind decisions/weights match
      (shared with model tests).
- [ ] After A(+B/C as applicable) verifier green, `.team/changelog.md` gains a plain-English M1
      filter-validation entry (client voice).

## Out of scope
