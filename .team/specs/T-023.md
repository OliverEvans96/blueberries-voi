# T-023 Belief API (`ShelfBelief`)

## Context

CTL policies need a single belief contract over MF ResearchParticleFilter marginals and B-state oracle truth.
ADR 0092 locks `ShelfBelief`; this ticket implements it under `filter/belief.py`.

## Acceptance criteria

- [ ] `ShelfBelief` is importable from `blueberries_voi.filter` (and usable from `controller` without
      importing `ResearchParticleFilter._state`).
- [ ] `shelf_belief_from_particle_filter_REMOVED(particle_filter, ...)` returns a `ShelfBelief` whose age representation is
      consistent with MF marginals of shape `(L, K)` (or list-of-lists floats of those dims) after a
      stepped production `ResearchParticleFilter` with `PRODUCTION_BACKEND == "mean_field"`.
- [ ] `shelf_belief_from_oracle(...)` returns a `ShelfBelief` of the **same public field set** from
      true lot counts/ages (B-state), without requiring an `ResearchParticleFilter` instance.
- [ ] `effective_inventory(belief, *, pending_orders, params, ...)` on a fixture matches hand-computed
      \(\tilde I_t\) using `survival_weighted_on_hand(..., from_marginals=True)` plus an explicit
      pipeline term from `pending_orders`.
- [ ] A unit test asserts CTL-facing code paths do **not** need attribute access to `ResearchParticleFilter._state`
      (factory + `effective_inventory` only).
- [ ] `ShelfBelief` fields (or a documented export helper) round-trip through list/float JSON-serialisable
      structures without numpy-only private handles as the sole public surface.
- [ ] `uv run pytest` for this ticket’s tests passes; no new runtime dependencies.

## Out of scope

- CTL-01 policy math beyond `effective_inventory`
- Joint / `K^L` belief factories
- Pyodide / FFI / worker packaging
- Writing figures or experiment markdown

## Interfaces

```text
ShelfBelief  # frozen public type (list/float-friendly fields preferred)
shelf_belief_from_particle_filter_REMOVED(particle_filter: ResearchParticleFilter, ...) -> ShelfBelief
shelf_belief_from_oracle(...) -> ShelfBelief
effective_inventory(belief: ShelfBelief, *, pending_orders, params, ...) -> float
```

Module: `blueberries_voi.filter.belief` (re-exported as agreed in ADR 0092).
