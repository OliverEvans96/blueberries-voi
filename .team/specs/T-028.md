## Context

CTL-01=C locks \(q_t=\mathrm{caseRound}(\rho[F^{-1}_{D_{t:t+L}}(\alpha)-\tilde I_t]^+)\) with default
ρ=0.8 until retuned. Implementation consumes `ShelfBelief` only (ADR 0092).

## Acceptance criteria

- [ ] A damped SW policy computes \(\tilde I_t\) via T-023 `effective_inventory` (MF marginals /
      `from_marginals=True` path) and emits case-rounded orders.
- [ ] With fixed `(ρ, α, belief, pending_orders, demand quantile)` fixtures, orders are **deterministic**
      and match a hand-computed table (including ρ≠1 damping).
- [ ] Default ρ is **0.8** unless overridden; α is an explicit constructor/config argument (tuned later
      by T-029).
- [ ] Policy never reads `ResearchParticleFilter._state`; tests construct beliefs via `shelf_belief_from_*` or fixtures.
- [ ] Protection interval uses daily LT=1 / same \(\Delta\tau_L\) convention as Rung 0 (documented).
- [ ] `uv run pytest` for this ticket’s tests passes.
