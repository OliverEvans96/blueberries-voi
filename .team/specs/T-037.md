# T-037 Outer-loop CRN cell (shared physics across scenarios)

## Context

SIM-02=C requires one shared physical realization per `(beta, replication)` across knowledge
scenarios. SIM-03=A requires burn-in before scored profit. This ticket builds the per-cell runner
that later sweeps call.

## Acceptance criteria

- [x] A public `voi` API runs one CRN cell: inputs include `beta`, `root_seed` / replication id,
      scenario list, burn-in / score lengths, and returns per-scenario **scored episode profits**
      (via `sim.profit.episode_profit`).
- [x] For a fixed `(beta, replication)`, demand / arrival / spoil streams are shared across
      scenarios (bit-stable under the same semantic slots); scenario differences come only from
      observation masks / belief construction.
- [x] Scored profit ignores burn-in days (`EpisodeLog.scored` / `n_burn` contract).
- [x] Cell supports at least **P0, P1, and B-state** in tests; other ADR 0096 columns may be
      wired here or completed in T-039, but the API must accept the full column name set.
- [x] Policy under each scenario is age-aware SW+rollout (or injectable policy for unit tests) —
      controller code is imported, not copied.
- [x] No matplotlib / parquet I/O inside the CRN module.

## Out of scope

- Full fine β grid orchestration (T-039)
- Bootstrap (T-038)
- Production-length experiments
