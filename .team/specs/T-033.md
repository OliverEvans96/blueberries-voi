# T-033 Multi-scenario closed-loop + L remeasure

## Context

M2 “multi-scenario” means closed-loop under different *beliefs* the policy sees (P1, B-state, Rung 0),
plus remeasuring empirical L under the real controller (FIL-13 follow-up). MF production stays.

## Acceptance criteria

- [ ] Closed-loop runs publish a short MD report comparing **P1** vs **B-state** vs **Rung 0**
      (primary scenarios); other masks have interface smoke only (no full profit claims required).
- [ ] Report lives under `experiments/` and/or `figures/m2/` — **not** under `controller/`.
- [ ] Empirical **L** under SW+rollout (or documented controller config) is recorded in the report.
- [ ] Report explicitly states production age backend remains **mean_field** (T-021 / ADR 0091); no
      recommendation to silently revert to joint.
- [ ] Primary physics path remains `day_step`; belief path uses `ShelfBelief` factories.
- [ ] `uv run pytest` smoke for the runner’s non-plot core passes (full MD may be experiment-only).

## Out of scope

- Dollar VOI tables across all M1.5 rungs
- SCN-B-clair foresight
- Reopening joint production
- Pyodide packaging

## Interfaces

```text
run_m2_multi_scenario(*, root_seed, ...) -> MultiScenarioResult
# writes experiments/.../*.md and optional figures/m2/*.png via viz/experiments
```
