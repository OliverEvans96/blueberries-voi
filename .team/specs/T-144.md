# T-144 — Move WASM worker into Vite graph

**Status:** implement  
**ADR:** [0139](../adr/0139-vite-bundled-wasm-worker.md) (supersedes ADR 0120 embed URL contract)

## Goal

Production build must bundle the WASM worker and wasm-pack output through the Vite
module graph. Dev-only middleware that served `/packaging/wasm/` and `/wasm/` is
retired.

## Acceptance criteria

- [ ] `web/src/engine/wasmWorker.ts` hosts demo hydrate + JSON RPC dispatch (ported from `packaging/wasm/worker.js`).
- [ ] `WasmAdapter` constructs `new Worker(new URL("./wasmWorker.ts", import.meta.url), { type: "module" })` by default.
- [ ] `./scripts/build-wasm.sh` writes wasm-pack output to `web/src/wasm/` (gitignored); copies to `packaging/wasm/pkg/` for Node smoke/bench fallback.
- [ ] `web/vite.config.ts` has no dev-only wasm static middleware; `.wasm` assets resolve in dev and production builds.
- [ ] Optional `VITE_WASM_WORKER_URL` / `VITE_WASM_ASSET_BASE_URL` env overrides remain for CDN hosting.
- [ ] `cd web && npm test` passes.
- [ ] `./scripts/build-wasm.sh` succeeds.

## Out of scope

- T-142/T-143 studioLogic scoping and CSS (parallel tickets).

## Files

| Path | Role |
|------|------|
| `web/src/engine/wasmWorker.ts` | Bundled module worker |
| `web/src/wasm/` | wasm-pack `--target web` output (gitignored) |
| `web/src/engine/wasmAdapter.ts` | Vite worker URL |
| `web/vite.config.ts` | Remove middleware |
| `scripts/build-wasm.sh` | Output path |
