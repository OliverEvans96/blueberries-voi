# T-155 Modal batch map for nb13 + gsin_upc_diag

## Goal

Fan out expensive independent simulation cells to Modal (optional) while keeping the
same functions runnable locally via `ProcessPoolExecutor`.

## Acceptance criteria

- [ ] **AC-1:** `blueberries_voi.experiments.filter_accuracy.run_seed_channel(seed,
  channel, n_days=…)` replays shared-order physics for one `(seed, channel)` with
  `n_rollout_paths=0`; returns a JSON-serializable dict with `mae_f` and channel key.
- [ ] **AC-2:** `all_channel_combos()` returns the 12 factorial channel combinations
  used by notebook 13 (2 pos × 3 waste × 2 delivery axes mapped to `ObsChannels`).
- [ ] **AC-3:** `merge_channel_rows(shards)` merges shard dicts into the notebook
  `channel_rows` schema (`seed`, `key`, `pos`, `waste`, `deliveries`, `preset`,
  `mae_f`, `mean_spread`).
- [ ] **AC-4:** `gsin_upc_diag` supports `--shard <regime_idx> <seed_idx>` emitting
  one JSON object with six per-channel metric records for that truth episode.
- [ ] **AC-5:** `blueberries_voi.experiments.gsin_upc.run_regime_seed(regime_index,
  seed_index)` returns shard JSON; `merge_gsin_diag_rows(shards)` reproduces the
  committed `experiments/data/gsin_upc_after.json` array shape (`regime`, `channel`,
  scalar metrics, `series`).
- [ ] **AC-6:** `experiments/modal/` documents wheel + binary build and exposes
  `modal run` entrypoints with `local_entrypoint` writing merged JSON locally.
- [ ] **AC-7:** Tests cover tiny `run_seed_channel` (≤3 days), merge schemas, and
  argument grids without calling live Modal.
- [ ] **AC-8:** `[project.optional-dependencies] modal` lists `modal`; package
  import works without it installed.
