# T-125 Retire Pyodide + HTTP API; WASM-only browser studio

## Context

T-121 Wave F moved all hot compute into `crates/voi_core` with WASM and PyO3 hosts. The studio still
carries three browser adapters (HTTP, Pyodide, WASM), Pyodide slim-wheel packaging, and a FastAPI
session API — redundant paths that ADR [0129](../adr/0129-retire-pyodide-http-wasm-only-studio.md)
retires in favor of WASM-only browser + native PyO3 Python workflows.

Concurrency plan: [T-125-concurrency.yaml](../plans/T-125-concurrency.yaml).
