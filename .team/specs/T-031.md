# T-031 CTL-06 toy exact DP certificate

## Context

CTL-06=A requires a toy-scale exact DP to report the optimality gap vs rollout — the certificate that
adjudicates whether single-step improvement is enough.

## Acceptance criteria

- [ ] `controller/toy_dp.py` (or agreed module) runs backward induction on a **small** state space
      (small demand support, truncated τ, ~2 lots) and returns an optimal value / policy table.
- [ ] A documented comparison reports the gap between toy-DP optimum and the rollout (or base)
      policy value on the **same** toy instance.
- [ ] β=1 / constant-\(w\) trap: test asserts age-aware and Rung 0 use the **same** protection
      interval \(\Delta\tau_L\) on the toy instance (CTL-06 trap).
- [ ] Module stays pure (no matplotlib / parquet); any figure is produced outside `controller/`.
- [ ] `uv run pytest` for this ticket’s tests passes.

## Out of scope

- Production-scale DP
- Full VOI claims from the toy gap
- Browser packaging
