## Interfaces

```text
POST /sessions                    -> { session_id }
POST /sessions/{id}/init          -> Snapshot
POST /sessions/{id}/step          body { order_qty: int } -> DayDelta
POST /sessions/{id}/step_n        body { orders: int[] } -> { deltas: DayDelta[] }
POST /sessions/{id}/reset         -> Snapshot
POST /sessions/{id}/act           body { policy?: str, budgets?: object } -> DayDelta
DELETE /sessions/{id}             -> 204
```

Error envelope: `{ "ok": false, "error": { "type": str, "message": str } }` or HTTP 4xx with
JSON body listing invalid fields.
