# T-017 Stage B + oracle ladder

## Context

FIL-11 Stage B checks calibration on rungs that Stage A passes; failing P0/P1 may run as
diagnostic-only. SCN-B-state provides a lot-level oracle ceiling (belief ≡ true state / filter
bypass) so F2 vs P1 information gaps are visible without B-clair foresight.

## Acceptance criteria

- [x] Stage B runs for each rung that Stage A marked pass (from T-016); produces 90% CI coverage
      and rank histograms; writes MD + figures under `figures/m1.5/` /
      `experiments/m15_stage_b_*.md`.
- [x] On rungs that Stage A failed, Stage B is either skipped or clearly labeled **diagnostic
      only** in the MD (same pattern as M1 post-A-fail).
- [x] Pass language observable: coverage within a documented band around 90%; ranks not strongly
      U-shaped or dome-shaped (metric or documented visual+numeric rule).
- [x] **Oracle ladder:** B-state path sets belief to true `(n, τ)` (or skips filter); age error is
      zero by construction in the harness.
- [x] Shared-CRN gap table: F2 posterior age error ≪ P1 error vs B-state on the same episodes
      (numeric table in MD); B-clair is not implemented.
- [x] No CTL / VOI sweep code.
- [x] Quality gates green for library code touched.

## Out of scope

- SCN-B-clair
- VOI dollar columns
- M1.5 close-out checklist (T-018)
- Re-running Stage C (T-012) except as dependency
