# T-045 Golden Snapshot / DayDelta fixtures + schema tests

## Context

Hosts and TypeScript adapters need bit-stable examples of the export contract. Depends on
EngineSession from T-043 (merge Wave 1 tip before starting).

## Acceptance criteria

- [ ] Golden JSON fixtures for at least one **Snapshot** and one **DayDelta** are committed under
      a documented path (e.g. `tests/fixtures/simulator/` or `src/blueberries_voi/simulator/fixtures/`).
- [ ] Schema tests load fixtures and assert required keys per ADR 0100 / T-043 Interfaces
      (`seq`, `episode_day`, flat `belief` fields on Snapshot; DayDelta `day` + `drop_oldest`).
- [ ] Schema tests assert **absence** of forbidden presentation keys: `economics`, `pnl_series`,
      `pnl_totals`, `ghost`, `ghost_deltas`, `heatmap`, nested `density`.
- [ ] A live `EngineSession` call under a fixed seed produces payloads that validate against the
      same schema helpers as the goldens (exact byte equality optional; schema + shape required).
- [ ] Flat belief: `len(age_marginals) == L * K` and `len(lot_counts) == L` and
      `len(tau_grid) == K` on goldens and live output.
- [ ] `uv run pytest` for these tests passes on CI Python versions available at merge time.

## Out of scope

- Wheel publishing (T-046)
- HTTP / OpenAPI (T-050–T-051)
- TS projector (T-054)

## Interfaces

```text
validate_snapshot(obj: Mapping) -> None  # raises on contract violation
validate_day_delta(obj: Mapping) -> None
```

Public validators may live under `blueberries_voi.simulator.schema` or tests-only helpers
re-exported for T-051.
