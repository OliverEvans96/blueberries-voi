# T-025 Day profit helper

## Context

CTL α-tuning and rollout need SIM-01=B day profit before M3 VOI. ADR 0093 places a pure helper in
`sim/profit.py`.

## Acceptance criteria

- [ ] `blueberries_voi.sim.profit` exports a day-level function such that for a toy `DayLog` (or
      equivalent fields) with known sales, waste, and demand,
      `day_profit == margin * sales - waste_cost * waste - stockout_penalty * max(0, demand - sales)`.
- [ ] Holding cost is **not** subtracted (SIM-01=B).
- [ ] Helper performs **no** filesystem I/O and imports no matplotlib.
- [ ] An episode helper (or documented reduction) sums day profits over **scored** days only when
      given an `EpisodeLog` with burn-in (SIM-03).
- [ ] Unit tests cover zero stockout, pure waste, and pure lost-sales cases.
- [ ] `uv run pytest` for this ticket’s tests passes; no new runtime dependencies.

## Out of scope

- VOI tables / scenario differences (`voi/` stays stub)
- Tuning α or writing experiment artifacts
- Changing `DayLog` schema unless a missing field blocks the formula (prefer pure function over schema churn)

## Interfaces

```text
# sim/profit.py
@dataclass(frozen=True)
class ProfitCosts:
    unit_margin: float
    waste_cost: float
    stockout_penalty: float

def day_profit(day: DayLog, costs: ProfitCosts) -> float: ...
def episode_profit(episode: EpisodeLog, costs: ProfitCosts) -> float: ...  # scored days only
```

Names may vary slightly; behaviour above is binding.
