# T-134 — Arrival freshness birth wiring (session / VOI / filter)

## Context

`rollout.rs` and `alpha_tune.rs` pass pre-sampled `delivery_f` and `age_at_receipt` into
`unit_day_step`, so physics birth matches the receipt metadata logged on `RichDay`. Production
`session.rs` and `voi.rs` still pass `delivery_f: None` / `age_at_receipt: None`, causing
`unit_day_step` to re-draw birth freshness from shipment RNG — decoupling truth inventory from
the arrival prior the filter and studio charts observe.

Studio WASM init sends `arrival_product` (`abdella_all` | `long_haul` | `short_haul`) but
does not embed shipment parquet; the session must hydrate MOD-21 demo traces from that key when
RPC omits explicit `shipments`.

ADR: [0138](../adr/0138-arrival-f-birth-wiring.md)

## Acceptance criteria

### AC-1 — Physics birth parity with rollout

- [ ] `session.rs` and `voi.rs` pass `delivery_f: f_at_receipt`, `age_at_receipt`, and
      `pack_age_mean: pack_date_days.map(f64::from)` into `UnitDayStepIn` (matching
      `rollout.rs`).
- [ ] When `delivery_f` is set, `unit_day_step` is called with `rng_ship` / `rng_sensor` as
      `None` (no double-draw).

### AC-2 — MOD-21 demo shipments + truth helper

- [ ] `shipments.rs` exports `mod21_demo_shipments(product: &str) -> Vec<ShipmentTrace>` with
      six calibrated 1 °C traces; `long_haul` omits S2, `short_haul` is S2 only.
- [ ] `truth_birth_from_trace(trace, params) -> f64` maps trace → `age_to_f(shipment_arrival_age)`.

### AC-3 — F2 filter birth from observed receipt age

- [ ] `unit_pf::birth_f` returns `birth_f_f2_dirac(age_at_receipt, η_ref)` when
      `obs.age_at_receipt` is present (before pack-date / mix paths).

### AC-4 — RPC configure hydrates shipments

- [ ] `parse_shipments_from_rpc` (or configure path) uses `mod21_demo_shipments` when no explicit
      `shipments` array is present but `arrival_product` is set on params or nested `config`.
- [ ] Default empty shipments → `mod21_demo_shipments("abdella_all")` so WASM studio matches mock
      mix prior without parquet.

### AC-5 — Regression tests green

- [ ] `cargo test -p voi_core` PASS (including new AC tests).
- [ ] `web` npm test PASS.

## Out of scope

- Regenerating VOI sweep artifacts.
- Editing `.github/workflows/`.
- Loading live Abdella parquet in WASM (demo traces only).
