# T-050 ASGI app wrapping EngineSession

## Context

Dev host: local HTTP sessions over the same export schema as Pyodide. Starts only after Slice 1
tip is verify-green. Parallel with T-051 after T-049 gate.

## Acceptance criteria

- [ ] Optional extra `[api]` installs the chosen ASGI stack (FastAPI or Starlette + JSON).
- [ ] ASGI app module is importable (documented entry, e.g. `blueberries_voi.api:app`) and
      creates server-side `EngineSession` instances keyed by `session_id`.
- [ ] Routes implement session create, `init`, `step`, `step_n`, `reset`, `act`, and delete per
      T-049 Interfaces; responses validate as Snapshot / DayDelta (no PnL/economics/ghost/heatmap
      keys).
- [ ] OpenAPI document is available from the app (FastAPI `/openapi.json` or equivalent export
      checked into tests).
- [ ] Unknown `session_id` returns HTTP 404 with a JSON error body.
- [ ] Invalid body (e.g. missing `order_qty` on step) returns HTTP 4xx with a JSON field list or
      explicit error type.
- [ ] `uv run pytest` for API tests passes; ruff/mypy clean for new modules.
- [ ] App import graph does not require matplotlib for serving interactive routes.

## Out of scope

- D3 HttpAdapter (T-056)
- Pyodide worker changes
- VOI / episode batch endpoints
