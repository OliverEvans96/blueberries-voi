# T-115 Studio show true state vs beliefs

## Context

Default studio charts overlay sim truth on belief surfaces. The produce-manager view
should show beliefs and books; a global accessible switch reveals truth in one visual
language. Presentation only (ADR [0125](../adr/0125-studio-show-truth-js-only.md));
the wire still includes `live_lots`.

## Acceptance criteria

- [ ] Fresh load with empty `localStorage` key `blueberries-voi-studio-show-truth` has `showTruth === false` (`cd web && npm test`).
- [ ] `saveShowTruth(true)` then `loadShowTruth()` returns true; the stored value is exactly `"true"` or `"false"` under that key.
- [ ] Belief heatmap draws `.truth-cross` (or equivalent overlay nodes) when truth lots are passed, and **zero** overlay nodes when `truthLots=[]` (`web/src/charts/beliefAgeCount` tests).
- [ ] Survival rug, history lot circles, and arrival-prior `age_at_receipt` marks have length 0 when gated off, and draw with `.truth-*` classes when lots/receipts are passed (`cd web && npm test`).
- [ ] Inventory vs target and age-composition series use expected counts/ages from `belief_history` when show-truth is off, and `history[].lots` / live lots when on.
- [ ] Projector `belief_history` length tracks the same rolling window as `history` after `applyDelta`/`applySnapshot`; Snapshot/DayDelta fixtures used in tests still **must not** include a `showTruth` engine key.
- [ ] Play chrome exposes a control with accessible name matching `/show true state/i`, `role="switch"`, and `aria-pressed` reflecting the flag; `#app` (or document body) has class `studio--show-truth` iff the switch is on.
- [ ] Belief section blurb does **not** require the word “truth” when show-truth is off; when on, captions/blurbs may mention overlay vs truth. `sections.belief.test.ts` is updated in this ticket (supersedes always-match `/truth/`).
- [ ] No production edits under `crates/`, `src/blueberries_voi/simulator/`, or wasm adapters for this ticket.

## Chart table (normative)

| Surface | Toggle off | Toggle on |
| --- | --- | --- |
| Belief heatmap | density only (`truthLots=[]`) | current overlays |
| Age marginal | unchanged (belief) | unchanged |
| Survival | Weibull curve; no lot rug | rug from `live_lots`, `.truth-*` |
| Store lots scatter | sales/spoil columns; no lot circles | lot circles with truth stroke |
| Age composition | stack from `beliefByDay` expected bands | stack from `history[].lots` |
| Inventory vs target | `on_hand` = Σ `lot_counts`; effective from belief ages | current `d.lots` sums |
| Arrival prior rug | PDF only | receipt-age rug |
| Sales, spoil, PnL, demand, orders, transit | always on | same |

## Out of scope

- Omitting `live_lots` from WASM/HTTP
- Per-scenario UI forks (knowledge-scenario audit)
- Changing filter/belief math
- Autopilot / policy using truth
- Editing `.github/workflows/`

## Interfaces

JS module (names may vary slightly):

- `loadShowTruth(): boolean` — default false
- `saveShowTruth(value: boolean): void` — `localStorage` key `blueberries-voi-studio-show-truth`
- `truthLots(show: boolean, lots: Lot[]): Lot[]` — `[]` when `show` is false

Projector ViewModel may expose `belief_history: { day: number; flatBelief: FlatBelief }[]`
(or equivalent) windowed with `history`. No new Snapshot/DayDelta fields.

Play chrome: `onShowTruthChange?: (show: boolean) => void`.
