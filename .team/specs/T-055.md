# T-055 PyodideAdapter → Release wheel (prod)

## Context

Production adapter talks to the T-047 worker and the GH Release wheel. Depends on T-047 artifact
and T-053 ADR.

## Acceptance criteria

- [ ] `PyodideAdapter` implements `EngineAdapter` and forwards to the worker RPC.
- [ ] Adapter never holds a PyProxy on the main thread; only plain data / JSON.
- [ ] `init` / `step` / `step_n` / `reset` (/ `act`) return Snapshot/DayDelta parsed for the
      projector.
- [ ] Integration smoke: load Release wheel URL (or fixture wheel) under Pyodide 314.0.4 and
      complete one init+step (script or CI job with clear pass/fail).
- [ ] Demo budget preset is the default for this adapter.

## Out of scope

- HttpAdapter (T-056)
- Studio default switch (T-057) beyond exporting the adapter module

## Interfaces

```text
class PyodideAdapter implements EngineAdapter {
  constructor(opts: { workerUrl: string; wheelUrl: string; budgets?: DemoBudgets })
}
```
