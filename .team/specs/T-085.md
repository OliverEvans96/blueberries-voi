# T-085 CAL-C1 — Web config Snapshot (schedule + demand summary)

## Context

Studio needs schedule + demand profile summary on Snapshot/config so C2/C3 can render calendar and
DOW chrome without inventing physics. Can start once export shapes from A2/B3 exist; mock may stub
profile.

## Acceptance criteria

- [ ] Snapshot / init config (Python export and/or TS types) exposes schedule fields: order weekdays
      and/or delivery weekdays, lead time, and enough info for UI to label weekdays from epoch.
- [ ] Snapshot / config exposes a **demand profile summary** suitable for charts (e.g. DOW means or
      multipliers + scale μ) — not necessarily the full JSON blob.
- [ ] Mock adapter (`web` mock generate/adapter) populates the new fields with coherent stubs when
      live engine is absent.
- [ ] Existing Snapshot golden / contract tests updated so forbidden keys remain forbidden and new
      keys are documented; no ViewModel/PnL leakage (ADR 0100 preserved).
- [ ] Typecheck / unit tests for TS types pass (`pnpm` / project web test command as used in ENG-01).
- [ ] Python export side (if touched) passes ruff/mypy on touched paths.

## Out of scope

- Next-order-day play button behaviour (T-086)
- Full demand UI polish / protection coverage chart (T-087)
- Changing CRN physics
