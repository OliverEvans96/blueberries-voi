# T-020 FIL-11 Stage C exact joint vs mean-field (FIL-04 check)

## Context

FIL-11 Stage C must double as the FIL-04 factorisation check. ADR 0090 locks a named
`sequential_wor_pmf` age likelihood and exact-joint vs mean-field APIs so Stage C compares posteriors
on fixed count paths without the tautological soft `sales_pow`/`waste_pow` stub, and without flipping
⚑ ADR 0049 / 0057 until a settle note recommends it.

## Acceptance criteria

- [ ] Module `blueberries_voi.filter.age_likelihood` exposes
      `log_p_sales_waste_given_ages`, `exact_joint_update`, and `mean_field_update` with the typed
      signatures in **Interfaces** (importable; mypy-clean under project strict settings).
- [ ] **Stage 0 pytest:** at `L=2`, `K=2`, `exact_joint_update` matches a hand-computed 2×2 posterior
      (total variation ≈ 0 within `1e-9`).
- [ ] **Stage 0 / unit:** shared LL is finite for feasible `(n, y)`; likelihood uses
      `death_prob_survival_ratio` and `picking_weights` from `blueberries_voi.model` (not forked
      formulas) — verified by import identity or call-site check in tests.
- [ ] `mean_field_update` returns an array of shape `(L, K)` whose rows sum to 1 (within float tol);
      the induced joint `∏ q_ℓ` is produced by a code path distinct from `exact_joint_update` (not
      the same algorithm aliased).
- [ ] Experiment `experiments/fil11_stage_c_mf.py` is runnable via documented `uv run`, and writes
      `experiments/fil11_stage_c_mf_result.md` with Stage 1–4 tables (TV / KL / MI / decision Δ) and
      an **explicit FIL-04 pass/fail recommendation** against ADR 0090 freeze gates.
- [ ] Figure of marginal TV vs σ at `L=3` is written under `figures/` (e.g.
      `figures/m1/fil11_stage_c_mf_tv_vs_sigma.png`).
- [ ] Does **not** modify production `_rbpf_update` / MC observation likelihood path (age_likelihood is additive only).
- [ ] Does **not** change `STATUS` of ADR 0049 (FIL-04) or ADR 0057 (FIL-12).
- [ ] After green verifier: `.team/changelog.md` gains a plain-English entry, and a settle note
      records a **recommendation only** (no board-status flip in this ticket).

## Out of scope

- Replacing the production soft observation likelihood in RBPF
- Full RBPF-vs-RBPF bakeoff
- Flipping ⚑ ADR 0049 / 0057 statuses
- Implementing the integral Wallenius PMF
- Multinomial allocation density (unless a follow-on ADR reopens after numeric failure)

```python
from blueberries_voi.filter.types import P1Obs
from blueberries_voi.model import ModelParams
import numpy as np
from numpy.typing import NDArray

# y is a P1 observation (sales_total, waste_total, arrivals). Stage C fixed-count
# paths may ignore arrivals when n is held fixed for the update under test.
def log_p_sales_waste_given_ages(
    n: Sequence[int] | NDArray[np.integer],
    tau: Sequence[float] | NDArray[np.floating],
    sales_tot: int,
    waste_tot: int,
    params: ModelParams,
) -> float: ...

def exact_joint_update(
    n: Sequence[int] | NDArray[np.integer],
    prior_joint: NDArray[np.floating],  # shape (K**L,), sums to 1
    y: P1Obs,
    params: ModelParams,
) -> NDArray[np.floating]:  # posterior_joint, shape (K**L,), sums to 1
    ...

def mean_field_update(
    n: Sequence[int] | NDArray[np.integer],
    prior_marginals: NDArray[np.floating],  # shape (L, K), rows sum to 1
    y: P1Obs,
    params: ModelParams,
) -> NDArray[np.floating]:  # posterior_marginals, shape (L, K), rows sum to 1
    ...
```

Likelihood semantics (ADR 0090): named `sequential_wor_pmf` (sequential WOR product ≡ sim law);
spoilage = independent Binomials via `death_prob_survival_ratio` after sales; P1 marginalizes latent
compositions; if `sales_tot < sum(n)` then `D = sales_tot`, else stockout. Mean-field: coordinate
ascent, max 5 sweeps, stop if max marginal TV change `< 1e-6`.
