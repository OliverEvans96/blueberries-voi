# T-079 CAL-A2 — Episode / session order gate

## Context

With `OrderSchedule` available (T-077), closed-loop episode, day_driver, open-loop, and interactive
session paths must only place orders on schedule days while still running daily `day_step`. May land
before day-indexed demand (T-082) via the ADR 0113 shim.

## Acceptance criteria

- [ ] Closed-loop episode runner consults `OrderSchedule.can_order(day)` (or equivalent default
      schedule): on non-order days the action applied to physics is `order_qty == 0` even if the
      policy returns nonzero.
- [ ] On order days, the policy’s order quantity is passed through (subject to existing rounding /
      clamps); a test shows at least one Sun/Tue/Thu day with nonzero order when the policy asks.
- [ ] `day_step` still runs every calendar day (age / demand / spoil / deliver events occur on
      non-order days); a multi-day log has contiguous day indices with demand drawn each day.
- [ ] Simulator `day_driver` / `EngineSession` step paths honor the same gate (order forced to 0 on
      non-order days).
- [ ] Open-loop / scripted order sequences: documented behaviour — either reject nonzero orders on
      non-order days or coerce to 0; tests lock the chosen behaviour.
- [ ] If `draw_demand` / `day_step` already accept `day=`, call sites pass the episode day; if not yet
      landed (pre-T-082), a thin compatibility shim keeps prior μ behaviour (ADR 0113).
- [ ] Existing episode tests updated or gated so they do not assume daily ordering without schedule;
      any guard that forbade non-daily cadence is updated **in this ticket** if it would block A2.
- [ ] Focused pytest green with `--no-cov`; ruff/mypy on touched paths pass.

## Out of scope

- Day-indexed SW / Rung0 protection formulas (T-081)
- Rollout H×7 / M2 gate retune (T-083)
- FreshNet profile / heterogeneous μ (T-080 / T-082)
- Web next-order-day button (T-086)

## Interfaces

```text
# Episode / session use DEFAULT_ORDER_SCHEDULE unless config overrides
run_closed_loop_episode(..., schedule: OrderSchedule | None = None)
# day_driver / EngineSession: same schedule field on init/config
```
