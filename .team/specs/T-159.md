# T-159 — Notify personal-website when docs-dist and studio releases publish

Closes GitHub issues #12 and #14.

## Goal

When CI publishes `docs-dist` on a main push, trigger a repository dispatch so
`OliverEvans96/personal-website` redeploys and picks up the latest VitePress
bundle at `/docs/blueberries/`.

When an immutable `studio-v*` release succeeds, dispatch personal-website so it
can open a semver bump PR (`blueberries-studio-published` with version payload).

Provision **`PERSONAL_WEBSITE_DISPATCH_PAT`** via SOPS + Terraform (GH #14), not
the GitHub UI.

## Acceptance criteria

### Docs dispatch (#12)

1. **AC-dispatch-step:** The `deploy` job in `packaging/github-workflows/ci.yml`
   has a step named `Notify personal-website to redeploy docs` using
   `peter-evans/repository-dispatch@v3` with `secrets.PERSONAL_WEBSITE_DISPATCH_PAT`,
   repository `OliverEvans96/personal-website`, and event-type
   `blueberries-docs-published`.
2. **AC-step-order:** The dispatch step runs after `Download studio dist artifact`
   and `Download docs dist artifact` in the `deploy` job. `docs-dist` is uploaded
   by the `docs` job (personal-website downloads that artifact from the successful
   main run); deploy does not re-upload artifacts.
3. **AC-main-only:** The dispatch step lives only in the existing `deploy` job
   (gated to main/master pushes).
4. **AC-guard-test:** `tests/test_docs_deploy_dispatch.py` asserts the packaging
   canonical YAML contract.

### Studio dispatch (#12 update)

5. **AC-studio-dispatch:** `packaging/github-workflows/release-studio.yml` dispatches
   `blueberries-studio-published` after immutable `studio-v*` release steps, with
   `client_payload.version` from `steps.pkg.outputs.version`.
6. **AC-studio-guard:** `tests/test_studio_release_dispatch.py` locks dispatch
   ordering, event type, and immutable-only gating.

### SOPS + Terraform (#14)

7. **AC-secrets-enc:** `secrets/secrets.enc.yaml` exists (SOPS-encrypted); plaintext
   never committed.
8. **AC-tf-secret:** `terraform apply` with `enable_github_actions = true` syncs
   `PERSONAL_WEBSITE_DISPATCH_PAT` via `github_actions_secret.personal_website_dispatch_pat`.
9. **AC-readmes:** `secrets/README.md` and `terraform/README.md` document bootstrap,
   rotation, and SOPS → TF → GitHub flow.
10. **AC-tf-guard:** `tests/test_github_actions_secrets_tf.py` asserts the scaffold.

### Docs

11. **AC-docs:** `packaging/github-workflows/README.md` documents dispatch steps,
   SOPS/Terraform secret provisioning, and human sync instructions.

## Implementation notes

- Edit `packaging/github-workflows/` only; human syncs to
  `.github/workflows/` via `./scripts/sync-github-workflows.sh`.
- Do **not** add `continue-on-error` on dispatch steps.
- `.sops.yaml` uses OpenPGP; mirror personal-website key holders.

## Out of scope

- Editing live `.github/workflows/`.
- Adding the PAT to personal-website (token is consumed only here).
