# T-071 Demo hydrate at API + Pyodide worker/RPC edges

## Context

Studio init/reset with missing `shipments` fails at `EngineSession`. Dual-mode
readiness needs deterministic demo hydrate at the **API and worker/RPC edges**
only (ADR 0107), without teaching `EngineSession` an Abdella FS default.

## Acceptance criteria

- [ ] When FastAPI `POST /sessions/{id}/init` receives a config **without**
      `shipments` (or with empty `shipments`), the handler injects a non-empty
      demo shipment list and returns **200** with a valid Snapshot (not 422).
- [ ] When FastAPI `POST /sessions/{id}/reset` receives a config without/empty
      `shipments`, the handler injects demo shipments and returns **200** Snapshot.
- [ ] When FastAPI init/reset receives **non-empty** client `shipments`, those
      values are preserved (not overwritten by the demo fixture).
- [ ] `packaging/pyodide/session_rpc.py` (and the worker dispatch path that
      mirrors it) hydrates missing/empty `shipments` on `init` and `reset` the
      same way before calling `EngineSession`.
- [ ] Direct `EngineSession.init({})` / init without shipments still raises
      `ValueError` (no Abdella FS default inside the session).
- [ ] Demo hydrate source is parquet-free (e.g. `smoke_cool_shipments()` or
      equivalent deterministic fixture) — tests must not require `data/abdella`.
- [ ] Focused tests under `tests/` prove the API and RPC hydrate behaviours
      above with `--no-cov` (qa RED → implement GREEN).

## Out of scope

- Vite wheel serving / `wheelUrl` (T-072)
- CORS middleware (T-073)
- Studio footer / env copy (T-074)
- Live browser smoke (T-075)
- Changing golden Snapshot schemas (ADR 0100)
- Arrival-only filter (T-067–T-069)

## Interfaces

- FastAPI: existing `/sessions/{id}/init` and `/sessions/{id}/reset` request
  bodies; when `config.shipments` absent/empty, server fills demo shipments
  before `EngineSession`.
- RPC: `handle_rpc` / `prepare_demo_config` (or successor) ensures
  `params.config.shipments` is non-empty before `EngineSession.init` / `reset`.
- Optional shared helper (e.g. `ensure_demo_shipments(config) -> dict`) may live
  under `blueberries_voi` or `packaging` as long as `EngineSession` stays strict.
