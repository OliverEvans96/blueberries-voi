# T-038 Paired bootstrap CI for VOI

## Context

VOI-03=B requires point estimates plus **paired** bootstrap confidence intervals on per-replication
differences — never a two-sample interval that discards CRN correlation.

## Acceptance criteria

- [ ] A public `voi.bootstrap` (or export) accepts paired per-replication arrays
      `(profit_scenario[r], profit_p0[r])` or precomputed `delta[r]` and returns a point estimate
      (mean delta) plus a CI `(low, high)` from paired bootstrap resampling of those differences.
- [ ] Bootstrap is seeded / reproducible given an explicit RNG or seed argument.
- [ ] Unit tests show that shuffling unpaired labels is **not** used; resampling is over
      replication indices applied to the paired differences.
- [ ] Helper can report CI on absolute deltas; percentage CI may be computed by bootstrapping
      paired percentage replicates (document which) — tests lock the chosen behaviour.
- [ ] No dependency on the full sweep to unit-test bootstrap math.

## Out of scope

- Plotting CI whiskers (T-040 / viz)
- Choosing production `n_bootstrap` beyond a documented default + smoke override
