# T-014 F1 / F1s lot-resolved likelihood

## Context

SCN-F1 presents age-/lot-resolved sales; SCN-F1s presents lot-resolved shrink. Under ADR 0086/0087
these are masked fields on `RichObs` scored by the shared MC likelihood. Default M1.5 F1 uses ρ=1
unbiased lot sales.

## Acceptance criteria

- [x] When `sales_by_lot` is present (F1 / F2 masks), the observation LL uses per-lot sales for those
      lots; a test shows updating lot A’s sales changes lot A’s age/count posterior more than lot B’s
      (cross-lot leakage bound documented).
- [x] When `waste_by_lot` is present (F1s / F2), per-lot waste similarly updates that lot; leakage
      test analogous to sales.
- [x] When those maps are `UNOBSERVED` (P0/P1), behaviour matches totals-only scoring from T-011 —
      no accidental empty-map conditioning.
- [x] F1 default ρ=1: `sales_by_lot` from DayLog is complete for sold lots; biased-ρ sampler is
      absent or clearly marked non-gate sensitivity.
- [x] Still one ResearchParticleFilter class / one MC LL entrypoint — no rung-specific ResearchParticleFilter subclass.
- [x] Quality gates green.

## Out of scope

- Biased early-adopter ρ&lt;1 as a DoD gate
- Exact per-lot forward algorithm (optional follow-on behind same interface)
- F2a/F2 prior injection (T-013)
- Multi-rung Stage A report (T-016)
