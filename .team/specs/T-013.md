# T-013 F2a pack-date prior + F2 age-at-receipt

## Context

SCN-F2a narrows the arrival-age prior from ASN pack date; SCN-F2 observes age at receipt (Dirac /
tight prior on the grid). Neither should invent new sales/waste likelihood structure — both write
into the cohort-birth prior channel (ADR 0086 / plan §3.3).

## Acceptance criteria

- [x] On a delivery day with F2a-unmasked `pack_date` / ASN hint, the new cohort’s arrival-age prior
      mass is **narrower** than the cold Abdella mix (observable: prior SD or HPD width strictly
      decreases vs unmasked/default prior under a fixed test fixture).
- [x] On a delivery day with F2-unmasked `age_at_receipt`, prior mass concentrates on the grid bin
      of measured τ_in (Dirac or documented tiny-width prior); ≥ documented fraction of mass in the
      nearest bin(s).
- [x] Under P0/P1 masks (pack_date / age_at_receipt UNOBSERVED), delivery prior injection matches
      the baseline Abdella mix — F2a/F2 code paths do not fire.
- [x] Sales/waste likelihood structure is unchanged by this ticket (no new soft terms); only the
      birth prior / `age_post` initialisation for the new lot changes.
- [x] Unit/integration tests cover: masked rung unchanged; F2a concentrates; F2 concentrates more
      tightly than F2a on the same fixture when both apply conceptually.
- [x] Quality gates green.

## Out of scope

- Cold-chain telemetry / EPCIS conditional hazard (SCN-F2 optional half — defer)
- Full age-resolved sales beyond existing F2 mask fields (overlap with F1 at ρ=1 owned with T-014)
- Stage A multi-rung publication (T-016)
- Biased transit uncertainty hyperparameters beyond a documented default
