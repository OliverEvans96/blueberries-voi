# T-140 Stage C — unified gamma-in-warped-time arrival model

## Context

T-138 (Stage A) added within-lot aleatoric birth dispersion via `arrival_dispersion_sd` and
truncated Normal on `f`. T-139 (Stage B) fixed F3 count bias and contrast hooks under that model.
Stage C replaces the hand-set F2a width (`f2a_transit_uncertainty_sd = 0.75`), the vestigial
`mix_arrival_f` fallback, and rounded-τ pack dates with one generative arrival law:

**per-unit transit age ~ Gamma(k·Λ, θ)** where Λ is Q10-warped transit duration and `(k, θ)` are the
shelf gamma parameters (`gamma_shape`, `gamma_scale`).

The `delivery_history` ladder becomes nested conditioning on progressively more of the transit
segment — temperature history fixes Λ, pack date fixes calendar duration `d` with `φ̄ ~ p(φ̄|fleet)`,
none bootstraps `(d, φ̄)` jointly from the fleet.

- [ ] **AC-1:** `shipments.rs` exports `calendar_transit_days`, `phi_bar_from_trace`,
  `phi_bar_fleet`, and `birth_f_units_gamma` (Gamma(kΛ, θ) → `age_to_f` per unit). Aleatoric

  production birth path (field may remain at 0.0 for wire compat or be removed with migration tests).

  round(calendar_transit_days(trace))`, not `round(tau)`. Filter F2a/F2 pack-date channel uses
  `d` with `φ̄` prior from `session.shipments`, not `Normal(d, f2a_transit_uncertainty_sd)`.

  is deleted. Default / none-channel birth bootstraps trace index from `session.shipments` (or
  caller-supplied fleet), not a hard-coded 3-trace list.
