# T-086 CAL-C2 — Next-order-day UI via step_n

## Context

Primary studio play action should advance to the next order day using existing `step_n` (zeros on
skip days + order on target), with calendar chrome showing weekday / pipeline.

## Acceptance criteria

- [ ] Primary play / advance control advances to the **next order day** (strictly after current day)
      via `step_n` with `order_qty=0` on intervening non-order days and a real order (policy or
      staged qty) on the target order day.
- [ ] Optional single-day step remains available for debugging if cheap; if omitted, document why.
- [ ] UI shows weekday labels derived from epoch `2024-01-01` + episode day.
- [ ] UI surfaces next delivery / pipeline hint consistent with LT=1 (order day → next-day delivery).
- [ ] Mock mode exercises the same advance semantics without a live wheel when using mock adapter.
- [ ] Manual or automated UI/smoke check recorded (screenshot note or playwright/unit) proving
      advance skips non-order days.
- [ ] Does not redefine OrderSchedule math in JS beyond consuming Snapshot schedule fields (ADR 0111).

- VOI smoke (T-088)
- Changing Python OrderSchedule defaults
