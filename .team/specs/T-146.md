# T-146 — Studio release and web CI workflow drafts

## Goal

Automate `studio-v*` GitHub Releases with a packed npm tarball and gate web changes on PRs.

## Acceptance criteria

1. `packaging/github-workflows/release-studio.yml` builds wasm, runs vitest, `build:lib`, `npm pack`, uploads tarball to GitHub Release on `studio-v*` tags.
2. `packaging/github-workflows/web-quality.yml` runs web vitest on PRs touching `web/`.
3. Tag namespace is `studio-v*` (not `v*`) to avoid the legacy Pyodide slim-wheel release workflow.
4. `packaging/README.md` documents the human copy step into `.github/workflows/` (agents must not edit live workflows).

## Out of scope

- Editing live `.github/workflows/` (human step).
