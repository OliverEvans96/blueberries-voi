# T-019 Sim emits ASN pack_date on DayLog (F2a Stage A unblock)

## Context

Oliver approved (2026-08-12): **definitely include pack date**. Stage A rung F2a
FAIL is blocked because `run_episode` always leaves `DayLog.pack_date = None`
even on delivery days, so the F2a mask and `arrival_age_prior_f2a` have nothing
real to observe. T-013 helpers and T-010 masks already exist; this ticket only
fills the sim emit gap (synthetic calendar pack date from transit age is OK —
Abdella traces do not ship ASN calendars).

## Acceptance criteria

- [x] On every delivery day (`arrivals > 0`), `DayLog.pack_date` is a real
      `datetime.date` (not `None`, not a numeric zero sentinel).
- [x] On non-delivery days (`arrivals == 0`), `pack_date` remains `None`
      (FIL-08: missing ≠ zero; do not invent a date).
- [x] Under shared CRN, identical `(root_seed, run_id, params)` yields identical
      per-day `pack_date` sequences (bitwise / equality stable with other DayLog
      scored aggregates).
- [x] `rich_obs_from_day_log(day, mask_for("F2a"))` exposes that `pack_date` as
      observed; `mask_for("P0")` / `mask_for("P1")` leave it `UNOBSERVED` even
      when the DayLog carries it (only F2a/F2-relevant fields per mask).
- [x] A delivery DayLog projected through the F2a mask yields a birth prior via
      `delivery_birth_age_prior` that is **strictly narrower** (SD) than the cold
      Abdella mix under the Stage A age grid.
- [x] `run_m15_stage_a(..., rungs=("F2a",), ...)` reports `contracted=True` for
      F2a under library smoke defaults (meaningful contraction vs cold prior when
      pack_date is present).
- [x] Quality gates stay green: `uv run ruff check .`, `uv run mypy src tests`,
      `uv run pytest` with coverage ≥80%.

## Out of scope

- Reopening ⚑ cards; CTL / VOI / browser
- Changing F2a transit-uncertainty width (`F2A_TRANSIT_UNCERTAINTY_SD`)
- New RichObs fields or mask table rows (T-010 stays)
- Re-litigating P0/P1 Stage A FAIL honesty
- Real ASN EDI ingest; synthetic pack date from `age_at_receipt` / episode day
      is accepted
