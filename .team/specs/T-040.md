# T-040 VOI smoke artifact, β=1 gate, figure hook

## Context

M3 needs an automated correctness gate (β=1 → near-zero information VOI) and a reproducible smoke
artifact / figure hook so ENG-03 static plots can be generated without putting matplotlib inside
`voi/` core modules.

## Acceptance criteria

- [ ] A smoke runner (library function and/or thin experiment helper) executes the ADR 0095 smoke
      sweep and writes a small markdown or JSON summary under `experiments/` (path documented).
- [ ] Automated test: under smoke budgets at **β=1**, absolute VOI vs P0 for each non-P0 column is
      near zero within a documented tolerance (or CI covers zero) — **CI red if violated**.
- [ ] A `viz` (or `experiments`) helper can produce a static matplotlib VOI-vs-β figure from a
      `VoISweepResult` without importing matplotlib from `voi.metric` / `voi.crn` / `voi.bootstrap`.
- [ ] Artifact documents that smoke numbers are not headline production VOI.

## Out of scope

- Full production-length sweep in CI
- Interactive Plotly (ENG-03=A)
- Browser packaging

## Interfaces

```python
def run_voi_smoke(*, root_seed: int = ..., report_path: Path | str = ...) -> VoISweepResult: ...
def assert_beta_one_voi_near_zero(result: VoISweepResult, *, tol: float = ...) -> None: ...
```
