# T-104 Rust physics kernels (voi_core)

## Context

ADR 0119/0121: port deterministic physics from `blueberries_voi.model.physics` into
`crates/voi_core`. Python modules stay. Citeable RNG stays Python.

## Acceptance criteria

- [ ] `voi_core` exports `weibull_survival`, `death_prob_survival_ratio`,
      `death_prob_hazard_product`, `q10_age_increment`, `picking_weights`.
- [ ] `cargo test -p voi_core` asserts those match Python float64 goldens to `atol=1e-12`
      (vectors: tau=0; tau=3, eta=14, beta=2; Q10 1 day 4C vs 0C q10=2).
- [ ] `allocate_sales` exists (Pcg64); tests check conservation (sales sum = min(demand, on_hand))
      and mean sales close to Python over many draws (not bit-identical).
- [ ] Existing Python `physics.py` is unchanged.
