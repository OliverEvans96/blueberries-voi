# T-003 Gate 0 and Abdella transit traces

## Context

X-13=A requires both Gate 0 calculations before/alongside the arrival generator. MOD-21=A requires
bootstrapping all six Abdella shipments. This ticket vendors or fetches traces, proves empirical
durations, and commits Gate 0a/0b figures.

## Acceptance criteria

- [ ] Abdella (or licensed derivative) temperature traces for **all six** shipments are present under
      `data/abdella/` (or a documented fetch script that populates it) with a license/provenance note
      (X-08 / MOD-21 / MOD-23).
- [ ] If fetch/vendor fails, the documented path is to **stop and ask Oliver** — tests must not
      invent synthetic temperature paths as a silent fallback.
- [ ] A unit/integration test asserts empirical harvest→end-of-chain calendar durations are in
      approximately **2.0–6.6 days** across the six shipments (matching MOD-21 published mix).
- [ ] Gate 0a script/module computes a variance decomposition of arrival effective age into
      **duration** vs **temperature** contributions and writes `figures/m1/gate0_variance.png` (or
      equivalent named artifact).
- [ ] Gate 0b script/module computes controller-sensitivity / caseRound swallow gap (true vs
      prior-mean age composition) under MOD-26 defaults (case size 8) and writes
      `figures/m1/gate0_caseround.png` (or equivalent).
- [ ] Gate 0b output reports whether the typical gap is **smaller than one case** at case size 8
      (and records the case-size-4 sensitivity number or a clearly marked TODO if deferred to the
      same script's second cell).
- [ ] Arrival effective-age spread under the all-six bootstrap is **nontrivial** (test: sample
      variance or IQR above a documented floor — not a delta mass).
- [ ] Running the Gate 0 entrypoint via `uv run` is documented in `figures/m1/README.md` (or
      `experiments/` README) mapping figures → X-13 / MOD-21.
