# T-142 — De-globalize studio mount (embeddable island prep)

## Goal

Studio must not assume it owns the whole document when embedded in Astro.

## Acceptance criteria

1. `initStudio(app)` resolves chart/footer/status/control nodes via `app.querySelector`, not `document.querySelector`.
2. Section keyboard shortcuts listen on the studio mount root (`app`), with cleanup on teardown.
3. `StudioProvider` accepts optional `containerRef`; standalone dev still mounts via `#app`.
4. `localStorage` keys in `sections.ts` and `showTruth.ts` use `bv-studio:` prefix.
5. `ReferenceDrawer` portals into a scoped host under `.bv-studio`, not bare `document.body`.
6. `reportStudioAdapterError` can resolve `#studio-error` from an optional mount root.
