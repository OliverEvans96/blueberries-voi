# T-024 Closed-loop driver + `Policy` protocol

## Context

M1 `sim.run_episode` is open-loop only. M2 needs a closed-loop episode driver that calls a `Policy`
each day, respects SIM-03 burn-in, and keeps SIM-05 CRN streams stable.

## Acceptance criteria

- [ ] A public `Policy` protocol (or ABC) exposes a method that, given day index + observable belief /
      state inputs agreed with T-023/T-026, returns a non-negative **order quantity** (int).
- [ ] `run_closed_loop_episode(...)` (name may vary; lives under `sim/`) runs burn-in + scored days
      using the **same** `model.day_step` physics path as today’s open-loop episode.
- [ ] With a constant-order policy, scored `DayLog.order_qty` equals that constant after case-size
      rounding rules shared with the sim (observable on returned `EpisodeLog`).
- [ ] Semantic RNG streams (`STREAM_DEMAND`, `STREAM_ALLOC`, `STREAM_SPOIL`, arrival streams) remain
      addressable via `spawn_rng`; adding an extra unused stream draw in a test does **not** change
      demand/alloc/spoil draws for the same `(root_seed, run_id, day, stream)` slots.
- [ ] Episode structure exposes `n_burn` / scored days consistent with SIM-03 (burn-in discarded for
      profit scoring consumers).
- [ ] Module stays free of matplotlib / parquet writes; figures remain outside `controller/` and this
      driver.
- [ ] `uv run pytest` for this ticket’s tests passes.

## Out of scope

- CTL-01 / Rung 0 policy implementations (T-027/T-028)
- Rollout lookahead (T-030)
- VOI aggregation
- Pyodide packaging

## Interfaces

```text
class Policy(Protocol):
    def order(self, ...) -> int: ...

run_closed_loop_episode(policy: Policy, *, params, root_seed, run_id, n_burn, n_score, ...) -> EpisodeLog
```

Exact `order(...)` argument list must include whatever T-023 exports for belief (or a hook that
builds `ShelfBelief`) plus pending pipeline state — freeze jointly with T-023 in review.

## Open questions

- [ ] Whether closed-loop lives as `sim/episode.py` vs extending `sim/__init__.py` — prefer a dedicated
      module if file size warrants; ADR not required if package boundary stays `sim/`.
- [ ] Filter step wiring (P1 mask each day) vs policy-supplied belief only — primary AC is Policy +
      CRN + day_step; P1 filter loop may be a thin helper in this ticket or T-028 integration.
