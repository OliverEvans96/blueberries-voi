# T-128 Observation channel toggles

## Context

Replace six ladder chips with three orthogonal toggle groups (POS, Waste, Deliveries).
Keep `ScenarioId` presets for VOI and guided paths. ADR [0133](../adr/0133-observation-channel-toggles.md).

Out of scope: MOD-16 multi-lot deliveries (T-129), `day_step.rs` delivery physics.

## Acceptance criteria

### Rust (`crates/voi_core/src/obs.rs`)

- [ ] `ObsChannels` struct with `pos`, `waste`, `deliveries` enums.
- [ ] `mask_from_channels` builds `ObsMask` per ADR 0133 table.
- [ ] `channels_for_preset` maps P0…F2; F2 uses pack_date not age_at_receipt.
- [ ] `mask_for(id)` ≡ `mask_from_channels(channels_for_preset(id))` minus age_at_receipt on F2.
- [ ] `channels_cache_key` canonical string for lazy caches.
- [ ] `validate_channels` rejects unknown enum strings.
- [ ] Inline tests: all 12 combos + preset round-trip + invalid enum.

### Rust session (`session.rs`)

- [ ] `set_obs_channels` with lazy catch-up (same as `set_obs_scenario`).
- [ ] Rung cache keyed by `channels_cache_key`, not ladder id only.
- [ ] RPC `set_obs_channels` + existing `set_obs_scenario` alias.
- [ ] `applied_config` includes `obs_channels` object.

- [ ] `ObsChannels` types + `mask_from_channels`, `channels_for_preset`, `channels_cache_key`.
- [ ] `PyEngineSession.set_obs_channels`.
