# T-139 Stage B — count_bias stability and contrast-sensitive scoring

## Context

T-138 (ADR 0139 Stage A) shipped within-lot aleatoric birth dispersion on truth and
filter with `STREAM_BIRTH`, zero-init filter banks, and LGTIN interval converse tests.
Homogeneous-fleet AC-12 drift guards pass for **P1** and **F2a**, but **F3**
(temperature-history channel) shows large alive-count bias drift when
`arrival_dispersion_sd` moves from `0.0` to `0.05` (~0.36 vs ≤0.11 guard). Stage B
addresses count conservation under dispersed births and prepares contrast-sensitive
scoring improvements deferred from ADR 0137.

## Acceptance criteria

### F3 count bias (AC-1–AC-2)

- [ ] **AC-1:** `lgtin_upc_homogeneous_fleet_count_bias_drift_guard` includes **F3** with
  `|mean_bias(sd=0.05)| ≤ |mean_bias(sd=0)| + 0.11` (same relative guard as P1/F2a on
  T-138 tip).
- [ ] **AC-2:** A named regression test documents the root cause if F3 required a channel-specific
  birth or observation mask fix (test name + one-line comment in `lgtin_upc_ac12.rs` or
  `t134_arrival_f.rs`).

### Filter mass conservation (AC-3–AC-4)

- [ ] **AC-3:** After filter birth with `arrival_dispersion_sd > 0`, expected alive units per
  particle row match `obs.arrivals` within `1e-9` (no phantom length inflation).
- [ ] **AC-4:** Session snapshot `lot_counts` sum tracks observed arrivals + decay over a fixed
  20-step fixture (seed sweep ≤200) with filter enabled from day 0.

### Contrast / allocation hooks (AC-5–AC-6)

- [ ] **AC-5:** `unit_ll` or `unit_pf` exposes a single documented entry point for
  contrast-sensitive spoilage weighting (function name in ADR 0140; no silent behaviour
  change at `arrival_dispersion_sd = 0`).
- [ ] **AC-6:** With `arrival_dispersion_sd = 0`, VOI CRN profits for seed `1` remain within
  `1e-6` of T-138 baseline for all seven scenarios (no Stage B regression at sd=0).

### Coverage / gates (AC-7)

- [ ] **AC-7:** CI verify on Python 3.11 reaches **≥80%** branch-aware coverage on
  `blueberries_voi` (closes T-138 remediate gap at 79.45%).

## Out of scope

- Multi-lot-per-delivery / MOD-16 option A (T-140).
- Studio UI slider for dispersion or contrast knobs.
- Changing ADR 0137 shared-decrement likelihood form outright (extensions only).

## Interfaces

- `ModelParams::arrival_dispersion_sd` — unchanged default `0.0`; F3 fixes must not break
  P1/F2a AC-12 guards.
- New or extended scoring hook per ADR 0140 (Rust `unit_pf` / `unit_ll` only in Stage B).
