# T-143 — Scope CSS under `.bv-studio` + self-host fonts

## Goal

Global studio CSS must not leak into an Astro host page.

## Acceptance criteria

1. Outermost studio wrapper uses class `.bv-studio` (`StudioLayout.tsx`).
2. Former global rules (`:root`, `html/body`, universal box-sizing) are scoped to `.bv-studio` subtree.
3. Google Fonts `<link>` removed from `index.html`; Fraunces + IBM Plex Sans loaded via `@font-face` from `public/fonts/*.woff2`.
4. Standalone Vite dev retains studio typography and page chrome.
