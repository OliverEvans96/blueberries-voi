# T-036 VOI metric (percentage + absolute vs P0)

## Context

VOI-01 requires every reported arm to expose both a **percentage** improvement vs P0 (headline) and
an **absolute dollar** delta (support). Metric helpers must be pure and unit-testable without running
a sweep.

## Acceptance criteria

- [ ] `blueberries_voi.voi.metric` (or equivalent public export) provides a function that, given
      `profit_scenario` and `profit_p0`, returns both `absolute_delta` (= scenario − P0) and
      `pct_vs_p0` (= absolute_delta / profit_p0 when profit_p0 ≠ 0).
- [ ] When `profit_p0 == 0`, the API raises a clear `ValueError` (or returns a documented sentinel
      agreed in tests) — no silent Inf/NaN in the happy path.
- [ ] Absolute delta is positive when the scenario profit exceeds P0; percentage uses the same sign.
- [ ] Unit tests cover positive, zero, and negative deltas without invoking the full sweep.
- [ ] `voi/__init__.py` exports the metric helper(s) (stub `__all__` no longer empty solely from
      this ticket if other modules absent — at minimum metric names are listed).

## Out of scope

- Bootstrap CIs (T-038)
- Outer-loop CRN / closed-loop (T-037)
- Fine β grid / figure generation

## Interfaces

```python
def voi_vs_p0(profit_scenario: float, profit_p0: float) -> VoIMetric:
```
