# T-154 Metrics titles, weight, and light narration

## Context

T-153 polished the metrics column layout (economics | inventory | flow) but left
left-column chart captions muted and impact stats visually heavy. Belief has a
panel head + note; metrics is a naked stack. This ticket boldens metrics chart
titles, de-emphasizes missed-sales/waste stats, and adds minimal first-time
orientation without per-chart blurbs.

## Acceptance criteria

- [ ] Metrics pane renders a `.panel-head` with `h2` text **Outcomes** and a
  `.panel-note` with exact copy: `Money, stock, and daily flow for this run.`
- [ ] Each existing metrics group shows a `.metrics-group-label` with exact
  copy: **Economics** on `.metrics-group--economics`, **Inventory** on
  `.metrics-group--inventory`, **Flow** on `.metrics-group--flow`
- [ ] Belief `.panel-note` (`#hover-note`) text is exactly:
  `Filter belief over time — hover a day to link charts.`
- [ ] `cockpitGrid.css` scopes bolder metrics captions:
  `.cockpit-pane--metrics .chart-caption` uses `font-weight: 700`, `font-size:
  0.8rem`, `color: var(--ink-soft)`, `letter-spacing: 0.03em`; uppercase
  preserved; Belief captions unchanged
- [ ] Impact stat label and value use regular weight (400–500 max); `.impact-stat-value`
  drops Fraunces (`var(--font-display)`), uses body font + tabular-nums; color
  `--ink-soft` throughout
- [ ] `ImpactStat` markup has no `<strong>` and no bold utility classes
- [ ] `StudioLayout.test.ts` asserts Outcomes head, three group labels, Belief
  note string, and metrics caption CSS rule presence in `cockpitGrid.css`
- [ ] `ImpactStat.test.ts` asserts no `<strong>` in rendered markup
- [ ] `pnpm exec vitest run` in `web/` passes for touched tests
