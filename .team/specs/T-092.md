# T-092 Fix Pyodide classic-worker failure (module worker + pyodide.mjs)

## Context

Pyodide **314.0.4** rejects classic workers. The packaging worker still uses
`importScripts(.../pyodide.js)`, and hosts spawn classic / default workers, so
the browser demo path fails at bootstrap. This ticket migrates to module workers
and ESM `pyodide.mjs` without downgrading the pin (ADR 0111).

## Acceptance criteria

- [ ] `packaging/pyodide/worker.js` does **not** call `importScripts` and does
      **not** load classic `pyodide.js`; it bootstraps via ESM
      `import { loadPyodide } from "…/pyodide/v314.0.4/full/pyodide.mjs"` (or
      equivalent static import of that URL).
- [ ] Worker still pins Pyodide **314.0.4**, resolves `wheelUrl` (query /
      fallback), answers JSON RPC (`init` / `step` / `step_n` / `reset` / `act`),
      and retains DEMO_BUDGETS / EngineSession binding behavior.
- [ ] `web/src/engine/pyodideAdapter.ts` constructs
      `new Worker(url, { type: "module" })` (not a classic / option-less Worker).
- [ ] `packaging/pyodide/main.js` constructs the worker with
      `{ type: "module" }` (not `{ type: "classic" }`).
- [ ] Vitest FakeWorker (or equivalent) asserts the Worker options include
      `{ type: "module" }` when `PyodideAdapter` is constructed.
- [ ] Automated contract / static tests fail if `worker.js` contains
      `importScripts` or lacks a `pyodide.mjs` reference under pin 314.0.4.
- [ ] No new Playwright (or other browser E2E) dependency is added unless one
      is already present in the repo lockfile / `web/package.json`.
- [ ] `.github/workflows/` is not modified; Pyodide is not downgraded below
      314.0.4.

## Out of scope

- Downgrading or unpinning Pyodide
- Editing live GitHub Actions workflows
- Changing RPC method set, DEMO_BUDGETS caps, or wheelUrl resolution semantics
- Live Playwright smoke (unless already wired); FakeWorker + static contracts
  are sufficient for this ticket
- Arrival-only filter / studio observation ladder work

## Interfaces

- Worker bootstrap: ESM `loadPyodide` from CDN `pyodide.mjs` under pin 314.0.4
- Host: `new Worker(workerUrl, { type: "module" })` from adapter + main harness
- Unchanged: JSON `{ id, method, params }` ↔ `{ id, ok, result | error }`;
  `?wheelUrl=` / Release fallback
