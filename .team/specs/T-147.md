# T-147 — Embed consumer smoke + EMBEDDING.md

## Goal

Document and prove that a third-party Vite host can consume the packed studio tarball.

## Acceptance criteria

1. `web/examples/embed/` is a minimal Vite + React 19 app depending on the workspace package (`file:../..`).
2. Example imports `Studio` and `@oliverevans96/blueberries-voi-studio/styles.css`.
3. `EMBEDDING.md` at repo root documents Astro island embedding with React 19 `client:only`, IntersectionObserver lazy import, and GitHub release tarball URL pattern (`studio-v*` tags).
4. `./scripts/build-wasm.sh && cd web && npm run build:lib && npm pack` produces a tarball the example can resolve via `file:` link.

## Out of scope

- Publishing to npm registry (GitHub release tarball only in docs).
- Production Astro site integration.

## Files

| Path | Role |
|------|------|
| `web/examples/embed/` | Consumer smoke app |
| `EMBEDDING.md` | Host integration guide |
