# T-002 Shared model kernels (MOD-12 day_step and physics)

## Context

Simulator and filter must share one transition implementation (ENG-02 / ENG-04). This ticket
implements the MOD-12 day step and constitutive kernels under interim M1 defaults so later sim and
filter code import the same objects.

## Acceptance criteria

- [ ] `model.day_step` applies events in order **age → demand → allocate sales → spoil survivors →
      deliver**; a unit test spies/asserts that order (MOD-12=A).
- [ ] Weibull death probability uses the **survival-ratio** form `1 - S(τ+Δτ)/S(τ)`, not `h(τ)·Δτ`;
      a property test shows material divergence from the hazard product at β=4.
- [ ] Q10 / Arrhenius in-store age increment at T_store=4 °C vs T_ref=0 °C matches the documented
      Q10=3.0 factor for a one-day step (within a stated numeric tolerance).
- [ ] Picking weights implement `w ∝ S(τ)^(1/σ)` at σ=0.5 and a uniform/random switch (MOD-25=B).
- [ ] Sequential without-replacement allocation (MOD-08=A) conserves sales: cohort sales sum to
      `min(demand, on_hand)` and no cohort goes negative.
- [ ] Demand draws are negative binomial with defaults μ=30 and V/M=2 (r=30) via the `:demand`
      stream (MOD-26=B / MOD-09=A).
- [ ] At β=1, age-aware and age-blind picking weights are identical (degeneracy assert).
- [ ] Cohorts with `n == 0` are dropped from the live set; cohorts with `n > 0` remain (FIL-14=A).
- [ ] `sim` and `filter` (even as stubs) import the **same** `day_step` symbol (shared-import gate);
      a test fails if either duplicates the transition logic.

## Out of scope

- Arrival-age bootstrap from Abdella (T-003/T-004)
- Full episode simulator, P1 observation masking, open-loop policy
- Particle filter / likelihood
