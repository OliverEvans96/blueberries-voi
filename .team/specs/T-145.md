# T-145 — Publishable studio library build

## Goal

Ship the React studio as an npm package consumable from Astro / Vite hosts without
owning the host document.

## Acceptance criteria

1. `web/src/embed.ts` exports `Studio` (`App` alias), `StudioProvider`, `StudioLayout`, and `StudioProviderProps`.
2. Styles are published at `@oliverevans96/blueberries-voi-studio/styles.css` (documented import path).
3. `web/package.json` uses scoped name `@oliverevans96/blueberries-voi-studio`, is not `private`, declares `peerDependencies` on React 19, and exposes `exports` for `.` and `./styles.css`.
4. `npm run build:lib` runs Vite library mode (`--mode lib`), externalizes React, emits `dist-lib/embed.js` + `.d.ts` + `styles.css`.
5. T-143 manual `.bv-studio` CSS scoping satisfies embed isolation (no extra postcss-prefix pass required).
6. `./scripts/build-wasm.sh && cd web && npm run build:lib && npm pack` succeeds on a clean tree with wasm built.

## Out of scope

- Live `.github/workflows/` edits (see T-146 draft).
- Astro host wiring (T-147).

## Files

| Path | Role |
|------|------|
| `web/src/embed.ts` | Library entry |
| `web/vite.config.ts` | Dual app / lib build |
| `web/package.json` | Package metadata + `build:lib` |
| `web/scripts/copy-lib-assets.mjs` | Fonts + CSS URL rewrite for tarball consumers |
