# T-123 Web studio React mirror (pixel parity)

## Context

Migrate the Vite studio entry from imperative `main.ts` DOM bootstrap to **React 19**
while preserving markup, CSS hooks, and D3 chart behavior. Scope is **`web/` only** (no
Python or CI workflow edits).

## Acceptance criteria

- [x] `web/package.json` includes `react`, `react-dom`, `@vitejs/plugin-react`, and
      `@testing-library/react` (dev).
- [x] Entry is `web/src/main.tsx` (+ `App.tsx`); `index.html` loads `main.tsx`.
- [x] `web/src/react/StudioLayout.tsx` renders the former `main.ts` shell (same ids/classes).
- [x] `web/src/react/StudioProvider.tsx` + `react/studioLogic.ts` boot adapter/D3 wiring after mount.
- [x] `web/src/react/D3ChartHost.tsx` provides stable chart mount nodes.
- [x] Play chrome and section controls port to React (`PlayChrome.tsx`, `SectionControls.tsx`
      via `controlsPlayMount.tsx` / `controlsSectionMount.tsx`) with the same HTML structure.
- [x] Legacy `web/src/main.ts` is gutted to re-export `main.tsx` only.
- [x] `cd web && npm test` — all vitest contracts pass (262 tests).
- [x] `cd web && npm run build` succeeds.

## Out of scope

- UX or layout changes
- Python / Rust backend
- `.github/workflows/`
