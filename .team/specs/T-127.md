# T-127 Cockpit Grid layout, tradeoff forecast RPC, and Events pane

## Context

T-126 shipped Layout 2 ("Tabbed Workbench"): `ChapterTabs` switches one `focus-plot` at a time,
`StoreChartTabs` pins the store left, and `DecisionRail` pins run controls right. The approved Layout 1
mockup (`layout-1-cockpit-grid.html`) instead keeps **Primary**, **Secondary**, **Economics**,
**Events**, and **Run** panes always visible in a fixed **3-row grid**, with a bottom **tuning dock**
tab strip (3 clusters + disabled "Future" chip).

This ticket implements Layout 1, adds WASM `tradeoff_forecast` and `events` RPCs, and wires frontend
tradeoff mini-charts plus a masked event log. Sampling semantics for display forecasts are locked in
ADR [0130](../adr/0130-tradeoff-forecast-sampling.md). Concurrency plan:
[T-127-concurrency.yaml](../plans/T-127-concurrency.yaml) /
[T-127-concurrency.md](../plans/T-127-concurrency.md).

### Primary / Secondary depth audit (documented gap — out of scope)

| Mockup expectation | Current `chart-history` / belief charts | Verdict |
|--------------------|----------------------------------------|---------|
| Sub-day interpolation between days on freshness×time heatmap | Day-indexed cells only; no sub-day interpolation | **Gap** — defer |
| Truth-toggle per-lot dots on Primary (size ∝ survivors, connecting lines) | Lots rug exists; no per-lot dot overlay with connecting lines | **Gap** — defer |
| Truth-toggle stacked bars on Secondary (current freshness histogram) | Age marginal / belief heatmap; no truth-bar overlay on Secondary pane | **Gap** — defer |

This ticket **promotes** existing chart hosts into always-on panes; it does **not** close the
interpolation/overlay gaps above.

### AC-rust-tradeoff — `tradeoff_forecast` RPC (`impl-rust`)

Files: `crates/voi_core/src/tradeoff.rs` (new), `crates/voi_core/src/session.rs`,
`crates/voi_core/src/lib.rs`, `crates/voi_core/benches/tradeoff_forecast.rs` (new).
Authority: ADR [0130](../adr/0130-tradeoff-forecast-sampling.md).

Algorithm (display forecast only — must **not** change `rollout_order` / Autopilot `act`):

- Candidate sweep: case-snapped `q` from `0` to `max(160, case_size * 20)` step `case_size` (matches
  `DecisionRail` slider).
- For each `q`, run `n_paths` Monte Carlo paths over **`protection_days`** (from
  `OrderSchedule.protection_days(current_day)`, typically 2–4 — **not** rollout `H`).
- Each path: resample starting unit freshness from `EngineSession.bank` via `systematic_resample`
  (ADR 0130); inject `q` per `lead_time_days`; accumulate `waste_total` and
  `demand.saturating_sub(sales_total)` per day via `unit_day_step`; **no terminal salvage**.
- CRN: RNG keyed on `seed` / `path` / `day`, **not** `q`.
- Per candidate: return mean, p10, p50, p90 for waste and missed; joint histogram over path samples
  (waste bins × missed bins).

- [ ] `handle_rpc` dispatches `"tradeoff_forecast"` on initialized session; unknown method still errors.
- [ ] Params (all optional): `{ "n_paths"?: u32, "protection_days"?: u32 }`. Defaults:
      `n_paths = session.n_paths` (configured rollout paths), `protection_days =
      schedule.protection_days(session.day)` when omitted.
- [ ] Response is a **single JSON object** with `candidates: QForecast[]` covering the **full** q-sweep
      (one entry per case-snapped candidate). Each `QForecast` includes at minimum:
      `q`, `waste_mean`, `waste_p10`, `waste_p50`, `waste_p90`, `missed_mean`, `missed_p10`,
      `missed_p50`, `missed_p90`, `joint_hist: { waste_bins: number[], missed_bins: number[],
      counts: number[][] }`.
- [ ] `tradeoff_forecast` does **not** advance `session.day` or mutate `richest_log` / `bank` beyond
      read-only resampling for simulation.
- [ ] Autopilot regression: for fixed seed/config, `act` / `rollout_order` chosen `q` is **unchanged**
      before vs after this ticket (`tests/test_t127_tradeoff_forecast.py`).
- [ ] ADR 0130 regression: at rung P0 with wide bank dispersion, p90−p10 waste bands are **strictly
      wider** than a mean-collapse seeding control (test may compare against internal flag or duplicate
      helper — observable via band width on fixed seed).
- [ ] Criterion bench `tradeoff_forecast` (smoke config: ~20 candidates, `n_paths=400`,
      `protection_days=3`) completes in **< 50 ms** median on CI hardware (generous gate; target
      single-digit ms per architect estimate). Bench file exists and `cargo bench --bench tradeoff_forecast`
      runs without error.

### AC-rust-events — `events` RPC (`impl-rust`)
