# T-044 Derived Abdella product + optional extras (browser-safe imports)

## Context

Browser / slim installs cannot depend on pyarrow or matplotlib. Abdella Parquet loaders must not
be imported eagerly on the interactive path. This ticket is independent of EngineSession (T-043).

## Acceptance criteria

- [ ] A **derived Abdella arrival-age product** (numpy- or JSON-friendly arrays / tables) can be
      built from the vendored Parquet sources via a documented offline or `uv run` script/command
      without requiring Pyodide.
- [ ] A loader API exists that reads the **derived** product and returns arrival-age data usable by
      sim / session config **without importing pyarrow**.
- [ ] Installing or importing the browser-oriented path does not pull matplotlib or pyarrow:
      documented `[browser]` (or equivalent) extra omits them, **or** core interactive modules
      import cleanly when those packages are absent (tests simulate absence via import guards /
      optional dependency checks).
- [ ] Eager imports of Abdella parquet I/O from modules on the interactive / browser import graph
      are removed or lazy-gated; a test fails if `blueberries_voi.simulator` (once present) or the
      documented browser entry module transitively imports `pyarrow` / `matplotlib` at import time.
      Until `simulator/` exists, the test targets the documented façade stub module or
      `model` arrival helpers introduced here — **must not block on T-043**.
- [ ] Desktop Gate 0 / data workflows remain available under a `[data]` (or equivalent) extra or
      documented desktop install that still uses pyarrow for Parquet (ADR 0085 preserved for
      desktop).
- [ ] `pyproject.toml` / lockfile updated for extras; `uv run ruff`, `mypy`, and `pytest` pass for
      the new loaders/tests.
- [ ] CI matrix change for Python **3.14** is either landed in this ticket or explicitly deferred
      with a checklist item pointing at T-046 — **prefer landing 3.14 job stub here if only
      `requires-python` / workflow matrix**; full pyemscripten wheel build stays T-046.

## Out of scope
