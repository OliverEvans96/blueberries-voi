# T-124 Studio UX revamp — audit remediation + IA + comprehension

## Context

T-119 audits ([controls/plots](../reports/studio-controls-plots-audit.md),
[knowledge-scenario](../reports/studio-knowledge-scenario-audit.md)) identified control↔plot gaps,
plot duplication, and scenario-blind presentation on an otherwise correct single-shell studio.
This ticket implements the approved remediation: a `scenarioAvailability` map, staged demand
preview, P&L/belief deduplication, and a comprehension-first information architecture (insight
strip, decision rail, chapter nav, glossary, day inspector, static VOI reference) — **JS only**,
no Python/wire changes. Authority: ADR [0086](../adr/0086-m15-richobs-unobserved-masks.md),
[0110](../adr/0110-studio-obs-scenario-ladder.md), [0123](../adr/0123-lazy-obs-scenario-filter-caches.md),
[0125](../adr/0125-studio-show-truth-js-only.md), [0128](../adr/0128-studio-ux-information-architecture.md).

Concurrency plan: [T-124-concurrency.yaml](../plans/T-124-concurrency.yaml).

## Acceptance criteria

### AC-avail — Scenario availability (T-119 scenario audit)

- [ ] `web/src/scenarioAvailability.ts` exports `plotAvailability(id, scenario)` and
      `controlAvailability(id, scenario)` with values `"show" | "dim" | "unavailable"` for all
      studio plot slots and section controls × six `ScenarioId` rungs, derived from ADR 0086
      `_SCENARIO_PRESENT`.
- [ ] On **P0**, the store spoilage chart slot renders an unavailable placeholder (muted hatch +
      caption) instead of plotting `waste_total`; `web/src/react/ChartUnavailable.test.tsx` passes.
- [ ] The arrival prior receipt rug is **unavailable** unless `obs_scenario === "F2"` or
      `showTruth` is on; `plotAvailability("plot-arrival-prior-rug", …)` drives the gate.
- [ ] `f2a_transit_sd` is **dim** on P0–F1s and **show** on F2a; `sensor_sigma` is **dim** on
      P0–F2a and **show** on F2.
- [ ] `web/src/scenarioAvailability.test.ts` asserts map completeness for all six scenarios ×
      every registered plot and control id (no missing keys).

### AC-demand — Staged demand preview (T-119 controls audit P1)

- [ ] `projector.demandSummaryFromConfig(partial)` returns an updated DOW summary from staged
      `demand_mu` / `demand_vm` without an engine Reset.
- [ ] Moving the Demand `demand_mu` slider updates `#chart-demand` within one animation frame
      (staged preview path); `web/src/engine/demandPreview.test.ts` passes.

### AC-dedup — Plot deduplication (T-119 controls audit P2/P5)

- [ ] Play section `plotIds` in `sections.ts` contains `plot-sales-demand` only — **no**
      `plot-belief` compact heatmap in Play.
- [ ] P&L appears as Run-panel totals + sparkline; Pricing section shows full cumulative series
      only behind an expandable "Full ledger" affordance (not three always-visible redundant surfaces).
- [ ] Dead `onObsScenario` duplicate callback is removed from `controls.ts`; only
      `onSetObsScenario` wires chip clicks.

### AC-tiers — Control update tiers (T-119 controls audit P3)

- [ ] Every slider and operational knob displays a tier badge: **Live**, **Preview**, **Reset**, or
      **Autopilot**, matching the code-inferred tiers in the T-119 control matrix.
- [ ] Play meta chrome exposes read-only `window_days` from `SimConfig`.

### AC-ia — Information architecture (UX plan)

- [ ] `InsightStrip` renders episode day (N/90), weekday + MWF delivery hint, active scenario title
      (ADR 0110 chip copy), and episode profit from `vm.pnl_totals`; test in
      `web/src/react/InsightStrip.test.tsx`.
- [ ] `DecisionRail` is sticky aside with Run controls, observation ladder chips (always visible),
      truth overlay toggle, and consolidated P&L; obs chips are **not** Belief-section-only;
      `web/src/react/DecisionRail.test.tsx` passes.
- [ ] Chapter nav groups sections into **Operate** (Play, Controller), **Understand** (Belief,
      Demand, Arrival), **Tune** (Physics, Logistics, Pricing) via `web/src/chapters.ts`; keyboard
      shortcuts 1–8 unchanged.
- [ ] `StudioLayout` uses a three-zone grid: store timeline | focus pane | decision rail; no layout
      fork per `obs_scenario`.

### AC-comp — Comprehension layer (UX plan)

- [ ] `paramLabels.ts` supplies plain-English labels and tooltips for all section sliders; stale
      "(fake)" Physics hint removed.
- [ ] `GlossaryDrawer` opens from a header affordance; entries align with ADR 0110 chip copy.
- [ ] `DayInspector` shows sales, waste, stockout, order qty, and a belief one-liner on day hover,
      wired from `studioLogic.ts` `onHoverDay`.
- [ ] `VoiReferencePanel` loads `web/public/voi-reference.json` stub with `generated_at` and a
      "demo run only" disclaimer; graceful empty state when JSON missing.
- [ ] `GuidedPaths` offers 3–4 presets that set scenario + section (+ optional Autoplay hint) in
      local state only.

### AC-a11y — Accessibility and polish (UX plan)

- [ ] `ShortcutHelp` modal opens on `?` and documents keys 1–8, arrow navigation, and truth toggle.
- [ ] Chart hosts expose `role="img"` and `aria-label` summaries; `@media (prefers-reduced-motion)`
      disables pulse animations.
- [ ] Responsive layout: ≥1100px three-column; 720–1100px rail as bottom sheet; <720px bottom tabs
      (`styles.css`).

### AC-verify — Integration gate

- [ ] `cd web && npm test` passes (all existing + new vitest files).
- [ ] `studioScenarios.test.ts` (or successor) confirms scenario switch updates gating without
      layout fork.
- [ ] Truth overlay behavior unchanged per ADR 0125 (global `showTruth` gate orthogonal to
      scenario availability).

## Out of scope

- Python, WASM, Pyodide, or Snapshot/DayDelta wire protocol changes
- Live citeable VOI computation or CAL-01 regen pipeline
- URL routing / deep links
- SCN-P2 seventh rung (ADR 0022 stays Out)
- Replacing D3 with another chart library
- Editing `.github/workflows/`
