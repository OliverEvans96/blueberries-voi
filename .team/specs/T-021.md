# T-021 Production RBPF → mean-field (FIL-13=B, FIL-04=C)

## Context

FIL-11 Stage C passed ADR 0090 freeze gates and recommended FIL-04 → C with FIL-13 production
aligned to bakeoff arm **B (`mean_field`)**. ADR 0091 locks that settle: production leaves
`full_joint` / joint→window fallback, wires real `mean_field_update` for P1 age belief, and keeps
MC observation likelihood for particle weights.

## Acceptance criteria

- [ ] `blueberries_voi.filter.PRODUCTION_BACKEND == "mean_field"`, and a newly constructed default
      `RBPF(...)` uses a backend whose `.name` (or equivalent public backend identity) is
      `"mean_field"` (observable via attribute / `backend_choice.backend` / particle state
      `backend` field — whichever the implementation exposes; must equal `"mean_field"`).
- [ ] On a **P1 fixture** with sales/waste totals observed and `sales_by_lot` / `waste_by_lot`
      `UNOBSERVED`, one production age-update step invokes
      `blueberries_voi.filter.age_likelihood.mean_field_update` (import identity or call-site
      spy); each particle’s posterior age rows are a simplex (rows sum to 1 within float tol);
      and under a non-flat likelihood the posterior differs from the prior (total variation of
      at least one lot marginal `> 0` within test tol).
- [ ] After a production `RBPF.step` (or equivalent predict/update), particle **weights** are
      still produced from `blueberries_voi.filter.backends.observation_loglik_mc` (import
      identity or call-site spy) — not replaced by `sequential_wor_pmf` / soft stub scoring.
- [ ] When `sales_by_lot` and/or `waste_by_lot` are **present** (F1/F1s-style maps), the lot-map
      path still runs: `_apply_lot_map_age_update` is invoked (spy/import identity), and age
      marginals for a lot with excess-above-equal-share evidence move relative to prior.
- [ ] `choose_backend(K, L, N)` returns `backend == "mean_field"` for configurations that would
      previously trip `MAX_JOINT_FLOATS` (e.g. production `K=8`, `N=2000`, `L` such that
      `K^L·N > MAX_JOINT_FLOATS`); `BackendChoice.L` equals the requested `L` (no silent
      truncation).
- [ ] Bakeoff registry still exposes arms A–E via `get_backend` /
      `blueberries_voi.filter.backends.BACKENDS` (`sliding_window`, `mean_field`, `bound_L`,
      `bootstrap_pf`, `full_joint`); invoking the **`full_joint`** bakeoff path still applies the
      joint memory guard (`guard_joint_memory` / `MemoryError` when over budget) for that arm
      only — production selection does not raise on the same `(K,L,N)`.
- [ ] ADR **0091** is `STATUS: ACCEPTED` (DATE 2026-08-12); ADR **0049** records FIL-04 → **C**
      (superseded/reopened per 0091); ADR **0082** and **0089** production defaults are marked
      superseded by 0091; ADR **0057** is marked historical; **no new runtime dependencies**
      appear in `pyproject.toml` / lockfile for this ticket.
- [ ] After green verifier: `.team/changelog.md` gains a plain-English entry describing the
      production mean-field settle.

## Out of scope

- Replacing MC observation likelihood with `sequential_wor_pmf` for particle weights
- Full RBPF-vs-RBPF re-bakeoff; VOI / controller work
- Removing bakeoff `full_joint` / `sliding_window` (or other A–E) backends
- New runtime dependencies
- Re-running FIL-11 Stage C experiment gates (evidence already accepted)
