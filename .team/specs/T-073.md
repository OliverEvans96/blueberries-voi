# T-073 API CORS for local Vite → FastAPI

## Context

The studio on Vite (`localhost` / `127.0.0.1`, port 5173 by default) cannot call
the local ASGI API cross-origin without CORS. Dual-mode HTTP mode needs
`CORSMiddleware` (ADR 0108).

## Acceptance criteria

- [ ] FastAPI app in `src/blueberries_voi/api/app.py` installs `CORSMiddleware`
      (or equivalent Starlette CORS) that allows origins matching local Vite
      development hosts: `http://localhost:*` and `http://127.0.0.1:*` for
      common Vite ports **or** an explicit allowlist including
      `http://localhost:5173` and `http://127.0.0.1:5173`.
- [ ] A preflight `OPTIONS` request to a session route from an allowed origin
      receives CORS success headers (`Access-Control-Allow-Origin` reflecting
      the request origin or an allowed pattern; methods include POST).
- [ ] A simple `POST /sessions` (or documented session create) from an allowed
      Origin header returns `Access-Control-Allow-Origin` in the response.
- [ ] Disallowed / missing CORS behaviour for non-localhost production-like
      origins is documented as out of scope (no wide `*` required for this
      ticket unless already the smallest correct Starlette config for regex
      localhost).
- [ ] Focused pytest under `tests/` proves CORS headers with `--no-cov`.
