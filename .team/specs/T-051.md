# T-051 API contract tests vs golden fixtures

## Context

Http path must match worker schema. Uses T-045 goldens and T-050 routes; may proceed in parallel
with T-050 once interfaces are frozen (tests can target TestClient against app under construction
on a branch that merges both). Prefer implementing against T-050 tip or a joint merge.

## Acceptance criteria

- [ ] Contract tests call HTTP `init` / `step` / `step_n` / `reset` / `act` via ASGI TestClient
      (or live local server) and validate responses with the same schema helpers as T-045.
- [ ] At least one test compares HTTP DayDelta/Snapshot shapes to golden fixtures (schema parity;
      exact seq values may differ if sessions are fresh — assert key sets + belief flat lengths).
- [ ] Tests assert forbidden presentation keys are absent from every interactive response.
- [ ] `step_n` with three orders returns three deltas (or framed list length 3).
- [ ] Failure path: bad session id → 404; malformed step body → 4xx.
- [ ] `uv run pytest` for these tests passes.

- Browser worker tests (T-047)
- UI wiring (T-057)

none beyond T-049/T-050
