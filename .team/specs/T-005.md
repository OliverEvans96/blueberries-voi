# T-005 FIL-13 tractability bakeoff

## Context

FIL-12=B full joint `K^L` is likely infeasible at realistic L. ADR 0082 leaves options A–E
**PROPOSED** until an in-repo runtime/accuracy bakeoff. This ticket produces that evidence for Oliver
to settle FIL-13 (and unblock FIL-15 K).

## Acceptance criteria

- [ ] Five backends are implemented behind one narrow interface (one-day predict/update given P1
      observations): `sliding_window` (A), `mean_field` (B), `bound_L` (C), `bootstrap_pf` (D),
      `full_joint` (E / FIL-12=B).
- [ ] From T-004 trajectories under interim defaults (σ=0.5, MOD-26 demand/case, FIL-14 extinction),
      the bakeoff reports empirical L distribution **p50 / p90 / max**.
- [ ] Microbench matrix runs over
      `(backend × K ∈ {4,6,8} × N ∈ {200,500,2000} × L_forced ∈ {2,3,4,6,8,12})` and records wall
      time, peak RSS (or equivalent), and OOM/timeout flags.
- [ ] Accuracy probe at L ∈ {2,3} reports total variation (or max abs error) vs an exact forward
      reference for backends that claim age-posterior correctness.
- [ ] Optional short end-to-end day on real sim trajectories runs until timeout and is logged without
      crashing the harness.
- [ ] Figure `figures/m1/fil13_runtime.png` (or equivalent) and a table/write-up under
      `experiments/fil13_bakeoff.md` (or `.team/`) are produced via documented `uv run`.
- [ ] Harness **does not** silently truncate L; if `full_joint` is uniquely accurate but exceeds a
      documented memory budget (e.g. `K^L · N > 5e7` floats) at measured L, the run fails loudly /
      escalates rather than pruning cohorts.
- [ ] ADR 0082 remains PROPOSED until Oliver records a choice; this ticket's DoD is evidence, not a
      silent decision.

## Out of scope
