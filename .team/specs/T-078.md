# T-078 CAL-B1 — FreshNet ingest + PROVENANCE

## Context

Track B needs a reproducible offline path to fetch FreshRetailNet-50K metadata/rows and document
provenance before fitting. Runtime and Pyodide must not depend on HF. Independent of OrderSchedule
(T-077).

## Acceptance criteria

- [ ] A script under `scripts/` (documented in module/docstring or PROVENANCE) can download or
      refresh FreshRetailNet-50K using the optional `[freshnet]` extra (not core deps).
- [ ] `pyproject.toml` declares optional `[freshnet]` extra listing HF/`datasets` (or equivalent)
      deps; core / `[browser]` install does **not** require them.
- [ ] `data/freshnet/PROVENANCE.md` exists and records: dataset id
      `Dingdong-Inc/FreshRetailNet-50K`, license (CC BY 4.0), access method, and placeholder or
      committed fields for download date / revision, SKU selection rule (IDs may be filled in T-080
      if selection needs exploratory stats — rule text must exist here).
- [ ] Importing `blueberries_voi` (or documented browser/slim entry) does **not** import `datasets`
      or huggingface hub clients; a test guards the interactive import graph.
- [ ] No `demand_profile.json` fit is required in this ticket (fit is T-080); ingest may write raw
      cache under gitignored paths (document path; do not commit multi-GB raw dumps).
- [ ] Script exits non-zero with a clear message if `[freshnet]` deps are missing.
- [ ] `uv run ruff` / `mypy` on touched paths pass; focused tests for provenance presence + no
      runtime HF import pass with `--no-cov`.

## Out of scope

- Fitting `demand_profile.json` (T-080)
- `draw_demand(day=)` (T-082)
- OrderSchedule / controllers
- Committing full raw parquet into git
