# T-141: Independent per-unit gamma aging and Poisson-binomial spoilage likelihood

## Context

ADR 0137 scored spoilage as a shared-decrement interval constraint: one latent `δ` per day
aged every live unit identically, so LGTIN `waste_by` could only falsify lot ordering, never
sharpen the posterior over freshness level. Ground truth and filter now draw **independent**
`δ_i` per live unit per day; spoilage is scored with an exact **Poisson-binomial** DP
(PMF + backward sampler), and a mandatory **`GammaDecrementTable`** (4096-bit grid, no
`thread_local`) supplies CDF/quantile/spoil probabilities for the adapted proposal.

## Acceptance criteria

### Physics table (AC-P1–P3)

- [ ] **AC-P1:** `physics::GammaDecrementTable` builds a 4096-entry grid keyed by freshness
  bits; exposes `cdf(f)`, `quantile(p)`, `spoil_prob(f)`, and `for_params(params)` rebuild.
- [ ] **AC-P2:** `t141_gamma_table` pins CDF monotonicity, quantile invertibility, and
  spoil_prob consistency with direct gamma math at representative `(shape, scale, f)` points.
- [ ] **AC-P3:** Table is passed explicitly (no `thread_local`); `for_params` invalidates on
  param change.

### Ground truth (AC-T1–T2)

- [ ] **AC-T1:** `unit_day_step` draws **independent** `δ_i` per live unit when
  `gamma_decrement` is `None`; fixed `Some(d)` remains a shared cap for deterministic tests.
- [ ] **AC-T2:** `t141_independent_aging` proves two units with identical pre-aging `f` can
  spoil independently (one dies, one survives) across repeated seeds.

### Likelihood and filter (AC-L1–L6)

- [ ] **AC-L1:** `unit_ll` exports `pb_log_pmf`, `pb_loglik_by_lot`, `pb_sample_deaths`,
  `spoil_probs_from_freshness`; interval primitives (`spoil_delta_interval*`,
  `delta_interval_loglik`, `DeltaInterval`, `DELTA_ANY`, `contrast_spoilage_weight`) are
  **deleted** (not `cfg`-gated).
- [ ] **AC-L2:** `t141_poisson_binomial` pins PMF normalization, DP loglik vs brute force
  on small cohorts, and backward sampler mass = exact PMF.
- [ ] **AC-L3:** `filter_step_unit` stage 1: backward-sample deaths from PB DP, truncated
  gamma survivors per unit, weight = exact PMF; LGTIN uses per-lot PB, UPC pools alive set.
- [ ] **AC-L4:** `filter_step_unit_with_birth_cached(..., table: &mut GammaDecrementTable)`
  is the production entry; session/VOI thread the table; convenience wrappers keep prior arity
  by allocating/rebuilding table locally.
- [ ] **AC-L5:** Guard tests in `unit_pf_ac` forbid reintroduction of deleted interval
  primitives and `contrast_spoilage_weight`; `tests/test_unit_pf.py` documents `pb_*`
  contracts instead of `delta_interval_*`.
- [ ] **AC-L6:** T-139 `lot_segment_has_spread` waste_by disable (unit_pf.rs ~359–366) is
  removed — lot-resolved waste is always scored when aligned.

### Diagnostics and regression (AC-G1–G4)

- [ ] **AC-G1:** Pre-change baseline saved as `experiments/data/lgtin_upc_pre_t141.json`
  (unmodified parent harness); README documents provenance.
- [ ] **AC-G2:** `lgtin_upc_diag` uses cached filter + table; regen produces
  `lgtin_upc_after.json` with **24 rows**; `notebook_14_source.md` §2/§5 and rebuilt
  notebook reflect independent-aging semantics.
- [ ] **AC-G3:** **`count_bias == 0`** (hard gate) on every scored rung with spoilage
  observation in regen JSON; `lgtin_upc_ac12` enforces `BIAS_MAX = 1e-9`.
- [ ] **AC-G4 (AC-G12):** Non-regression guard — for each comparable metric row, LGTIN ≤ UPC
  counterpart (store mean-f MAE, per-lot MAE, ESS); measured and documented in review, not
  required to strictly improve.

### Docs and closeout (AC-D1–D2)

- [ ] **AC-D1:** ADR **0143** accepted; ADR **0137** carries `SUPERSEDED-BY 0143`; ADR
  **0133** footnote on spoil channel; `INDEX.md` lists 0143.
- [ ] **AC-D2:** Full verify gate PASS on Python 3.11 (ruff, mypy, pytest ≥80% cov,

## Out of scope

- Demand-censoring / stockout scoring (P0 count bias beyond zero-spoil rungs).
- Binned-freshness DP or τ-clock retirement.
- VOI profit monotonicity across rungs (controller ticket).
- Pyodide/wasm binding surface beyond table threading already in session.
