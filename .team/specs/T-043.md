# T-043 EngineSession façade + closed-loop day driver + act / step_n

## Context

Slice 1 needs one Python interactive façade that hosts and workers will share. Today closed-loop
drivers live under `sim/` and VOI/M2 loops; there is no `simulator/` module returning Snapshot /
DayDelta. This ticket is independent of Abdella packaging (T-044).

## Acceptance criteria

- [ ] Package module `src/blueberries_voi/simulator/` exists and is importable via
      `import blueberries_voi.simulator`.
- [ ] `EngineSession` exposes `init`, `step`, `step_n`, `reset`, and `act` callables (methods)
      documented in Interfaces below.
- [ ] `init` / `reset` return a **Snapshot** dict whose top-level keys include `seq`,
      `episode_day`, and `belief` with flat fields `lot_counts`, `age_marginals` (length `L*K`),
      `tau_grid`, `L`, `K`.
- [ ] `step` returns a **DayDelta** dict with `seq`, `episode_day`, and a single `day` object;
      `step_n` with `k` orders returns a sequence of exactly `k` DayDelta dicts (or a framed
      object whose `deltas` list has length `k`).
- [ ] JSON round-trip (`json.dumps` → `json.loads`) of Snapshot and DayDelta succeeds in tests;
      decoded payloads contain **no** keys named `economics`, `pnl_series`, `pnl_totals`,
      `ghost`, `ghost_deltas`, or `heatmap` / `density`.
- [ ] `act` selects an order via the controller surface (budget knobs accepted) and advances one
      day equivalently to supplying that order to `step` (same DayDelta shape).
- [ ] Session accepts first-class budget knobs including at least `n_particles`, `H`,
      `n_rollout_paths`, and candidate radius (names may match controller defaults); a documented
      browser demo preset uses values ≤ production defaults (e.g. `n_particles≤200`, `H≤7`,
      `n_rollout_paths≤2`).
- [ ] Shared day driver used by the session performs order → pending/arrival → `day_step` →
      observation → optional ResearchParticleFilter → belief → DayDelta without importing matplotlib or pyarrow.
- [ ] `uv run pytest` covering the new module passes; `uv run mypy src tests` and
      `uv run ruff check .` remain clean for touched paths.

## Interfaces

```text
# blueberries_voi.simulator (public)

class EngineSession:
    def init(self, config: Mapping[str, Any], *, seed: int | None = ...) -> Snapshot: ...
    def reset(self, config: Mapping[str, Any] | None = ..., *, seed: int | None = ...) -> Snapshot: ...
    def step(self, order_qty: int) -> DayDelta: ...
    def step_n(self, orders: Sequence[int]) -> list[DayDelta]: ...
    def act(self, *, policy: str | None = ..., **budget_overrides: Any) -> DayDelta: ...

Snapshot = {
  "seq": int,
  "episode_day": int,
  "applied_config": Mapping[str, Any],
  "history": list[Day],           # window
  "belief": FlatBelief,
  "live_lots": list[Mapping],
  "pipeline": list[Mapping] | Mapping,
  ...
}

DayDelta = {
  "seq": int,
  "episode_day": int,
  "day": Day,
  "live_lots": list[Mapping],
  "pipeline": list[Mapping] | Mapping,
  "belief": FlatBelief | omitted when unchanged/disabled,
  "drop_oldest": bool,
  ...
}

FlatBelief = {
  "lot_counts": list[float],      # len L
  "age_marginals": list[float],   # len L*K row-major
  "tau_grid": list[float],        # len K
  "L": int,
  "K": int,
}
```

Internal nested `ShelfBelief` may remain; wire flatten is required at the session boundary
(ADR 0100).
