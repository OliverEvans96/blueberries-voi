# T-097 EngineSession.act — damped_sw + SW-based rollout

## Context

Studio Autopilot (ADR [0112](../adr/0112-studio-autopilot-mode.md)) needs
`EngineSession.act` to select orders with the M2 damped survival-weighted family
and to wrap rollout around that base — not `ConstantOrderPolicy(0)`. ASGI already
forwards `policy` + `budgets`; Python `_select_order` must grow aliases and
budget knobs.

## Acceptance criteria

- [ ] `EngineSession.act(policy="damped_sw", ...)` and `policy="sw"` return a
      DayDelta that advances one episode day (same top-level DayDelta shape as
      `step`), without raising `unknown policy`.
- [ ] For `damped_sw` / `sw`, order selection uses `DampedSurvivalWeightedPolicy`
      with `alpha` and `rho` taken from budget overrides when provided; when
      omitted, `alpha` defaults to **0.9** and `rho` to **0.8**.
- [ ] `act(policy="rollout")` (also `ctl`, `rollout_order`) calls `rollout_order`
      with `base_policy` an instance of `DampedSurvivalWeightedPolicy` (same
      alpha/rho defaults/overrides as above) — **not** `ConstantOrderPolicy(0)`.
- [ ] Existing `constant` / `const` / `fixed` behavior still works (`order_qty` /
      `q` overrides); unknown policy names still raise `ValueError` mentioning
      allowed names including `damped_sw` and `rollout`.
- [ ] Budget overrides `H`, `n_rollout_paths`, `candidate_case_radius`,
      `n_particles` continue to update session dials and affect rollout as today.
- [ ] ASGI `POST .../act` with body `{ "policy": "damped_sw", "budgets": { "alpha": 0.9, "rho": 0.8 } }`
      succeeds (200) and returns a DayDelta JSON object (existing app already
      forwards `**budgets`; update/add API or session tests as needed).
- [ ] Pytest covers: damped_sw alias; alpha/rho override vs defaults; rollout base
      type is damped SW (inspect via unit test of `_select_order` or equivalent
      observable — e.g. monkeypatch/`isinstance` on constructed base, or a
      dedicated test helper); constant regression; unknown policy error text.
- [ ] If packaging/worker smoke scripts assert allowed `act` policies, they are
      updated in this ticket so `damped_sw` is accepted (no stale “constant or
      rollout only” copy).
