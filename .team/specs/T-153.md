# T-153: Studio UI visual polish

## Summary

Polish the WASM studio cockpit metrics column hierarchy, re-separate orders vs spoilage charts with independent y-scales and restored spoil-hover → 2D hist focus, improve events typography, and tighten CSS rhythm across economics | inventory | flow blocks.

## Acceptance criteria

### Metrics column order

1. `#pnl-totals-host` (Revenue · Cost · Profit)
2. Compact impact row: `#impact-missed-host` + `#impact-waste-host` adjacent under totals
3. Cumulative P&L chart (`#chart-pnl-economics`)
4. On-hand by freshness (`#chart-age-comp`) + Effective inventory (`#chart-inventory`)
5. Orders alone (`#chart-controller-orders` via `renderControllerOrders`)
6. Spoilage alone (`#chart-spoil`, independent y-scale)
7. Sales & demand (`#chart-sales-demand`)

### Orders / spoilage

- Remove combined shared-scale `renderOrdersWaste` from metrics mount (helper may remain for migration).
- Autopilot focus: split orders + spoil hosts to match metrics (replace combined `#chart-orders-waste-focus` pattern).
- Hover: `#chart-spoil` → `"spoilage"` → `BeliefFreshnessHoverFocus "spoiled"` on freshness × time (mirror sales path).

### Events typography

- Stronger day title vs body; totals bolder/larger than lot rows; column titles caption-like.
- Tighter lot spacing, slightly more space under day header.
- Single CSS source of truth in `eventsPane.css`; delete conflicting events rules from `cockpitGrid.css`.

### Polish

- Group gaps between economics | inventory | flow blocks (~0.65–0.75rem inter-group).
- Sales/P&L taller than secondary strips (e.g. 150 vs 120px).
- Caption top margin as separator within groups.
- Belief 1D hist slightly reduced vs hero 2D hist.

### Tests

- Layout tests asserting `#chart-spoil` absent → expect present.
- Hover source + spoil focus on 2D hist.
- Impact host order smoke if useful.
- Update `main.stockout.test.ts`, `studio-visual-qa.spec.ts` as needed.

## Out of scope

- Tuning dock redesign, EconomicsPane revival, dual-axis combo chart, `.github/workflows` edits.
