# T-136 Unify P1/F1 sales likelihood in unit particle filter

## Context

The production unit PF scores sales via noisy single-path MC draws that compound with lot count (F1
worse than P1), never scores the cross-lot split, and never removes sold units from particle state.
This ticket lands the unified design in ADR 0135: deterministic feasibility + multinomial allocation
likelihood, plus unscored WOR state-transition removal.

## Acceptance criteria

- [ ] `p1_totals_loglik` and `loglik_sales_by_units` take no `rng` parameter; sales scoring in
  importance weights is deterministic (feasibility gates + binomial waste unchanged; F1 adds
  multinomial cross-lot term from pooled `picking_weights_f` lot shares).
- [ ] `sequential_kernel_path_logprob` takes `freshness: &mut [f64]` and zeroes picked slots;
  `score_particle` takes `&mut [f64]`, applies unscored WOR removal **after** finite likelihood
  (P1 pooled, F1 per-lot conditional on `sales_by`), with waste computed on pre-removal freshness.
- [ ] `filter_step_unit` scoring loop passes `&mut bank.freshness[p]` through `score_particle`.
- [ ] Existing test `sequential_kernel_path_logprob_feasible_finite` updated for mutable freshness
  and asserts picked slots read `f <= 0.0` after the call.
- [ ] Existing test `p1_totals_loglik_impossible_sales_neg_inf` updated (no `rng` arg); still
  returns `-inf` for infeasible sales.
- [ ] `unit_pf_l20_scripted_mean_f_mae_and_order_match` re-run and re-baselined with documented
  before/after; P1 mean_f MAE still under threshold and order match preserved.
- [ ] **New:** F1-vs-P1 relative MAE — on the same scripted L=20 episode with arrivals, F1
  `mean_f` MAE ≤ P1 `mean_f` MAE (`unit_pf_f1_p1_relative_mean_f_mae`).
- [ ] **New:** heterogeneous two-lot script where F1 **strictly** outperforms P1 on mean_f MAE
  (`unit_pf_f1_strictly_beats_p1_heterogeneous_lots`).
- [ ] **New:** exact-path-enumeration spot check at `L ≤ 3`, small `sales_tot`, comparing true
  weighted WOR split distribution vs multinomial approximation (TV distance under documented
  tolerance) (`multinomial_vs_exact_wor_split_small_l`).
- [ ] **New:** Monte Carlo distributional comparison at realistic `L` (e.g. 20), empirical lot-split
  frequencies from pooled-WOR trials vs `lot_share` (`multinomial_vs_wor_mc_realistic_l`).
- [ ] `tests/test_unit_pf.py` hand-reference docs updated for new deterministic contract; new Rust
  test names wired into `_cargo_unit_pf_ac(...)`.
- [ ] `experiments/c2_a_totals_study.md` regenerated via bench and figures re-documented.
- [ ] ADR 0135 committed; `.team/changelog.md` plain-English entry on verify PASS.

## Out of scope

- Regenerating previously published VOI sweep artifacts (profit deltas under old filter).
- Changes to waste likelihood functions (`loglik_waste_by_units`, `loglik_waste_tot_after_sales_by`,
  `binom_pmf`).
- Exact (non-approximated) Wallenius scoring as production likelihood.
- Binned-freshness DP upgrade (deferred per ADR 0135).
