# T-016 Multi-rung Stage A (shared CRN)

## Context

FIL-11 Stage A must run across M2.5 data-availability rungs under shared CRN so differences are
informational. P0/P1 may still fail under defaults after honest LL; F2a/F2 (and ideally F1/F1s)
should show contraction. Cohort-from-birth metrics avoid oldest-slot artifacts when L_filter &lt;
empirical L.

## Acceptance criteria

- [x] Runnable experiment covers rungs **{P0, P1, F1, F1s, F2a, F2}** with a **shared**
      `root_seed` / SIM-05 streams; only the observation mask differs.
- [x] Each rung reports prior vs posterior arrival-age spread (cohort-from-birth metric documented)
      and a boolean/pass flag using a documented margin (e.g. ≥5% SD contraction) plus tight-prior
      control collapse.
- [x] Result MD under `experiments/` (e.g. `m25_stage_a_result.md`) publishes a plain table; **P0/P1
      FAIL is allowed** if documented; higher-rung expectations (F2a/F2 should PASS) are stated
      honestly when they fail (needs-human, not papered over).
- [x] Figures land under `figures/m2.5/` with README mapping figure → rung / FIL-11.
- [x] Does not claim VOI dollars; no CTL code.
- [x] Quality gates green for any new library helpers; experiment scripts may live under
      `experiments/` per ENG-04 norms.
