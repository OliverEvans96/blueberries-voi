# T-009 Rich DayLog / SIM-04 emit

## Context

`day_step` already returns `sales_by_cohort` / `waste_by_cohort`, but `run_episode` drops them and
`DayLog` only stores totals. M2.5 needs the richest ground-truth log every day so masks can project
observations without a second simulator fork (SIM-04 / plan §3.6).

## Acceptance criteria

- [x] After `run_episode`, each `DayLog` includes **per-lot** sales and waste maps keyed by
      `lot_id` (or an equivalent ordered structure that round-trips to lot ids), not only totals.
- [x] Each `DayLog` records end-of-day live lot state with `n`, `tau`, and `lot_id` (existing
      `lots` may be extended, not replaced).
- [x] On delivery days, the log exposes receipt metadata needed by F2a/F2: at least
      `age_at_receipt` for the new lot and a `pack_date` (or ASN age-hint) field when the arrival
      generator can supply it; non-delivery days leave these unset/`None` (not zeroed into truth).
- [x] Totals remain consistent: `sales_total == sum(sales_by_lot.values())` and
      `waste_total == sum(waste_by_lot.values())` for every logged day (empty maps when zero).
- [x] Shared CRN regression: identical `(root_seed, run_id, params)` yields bitwise-identical
      existing scored aggregates (`sales_total`, `waste_total`, `arrivals`, `demand`, `L`) vs pre-change
      baseline within the test suite.
- [x] Filter still imports `model.day_step` for transitions; sim does not duplicate spoilage /
      allocation formulas (ENG-02 identity assertion still passes).
- [x] `uv run ruff check .`, `uv run mypy src tests`, and `uv run pytest` stay green with
      coverage ≥80%.

## Out of scope

- Changing the observation likelihood (T-011)
- `RichObs` / masks (T-010) — this ticket only enriches the sim log
- Controller / VOI / browser
- Biased F1 ρ sampling

## Interfaces

```python
# blueberries_voi.sim (extensions; indicative)

@dataclass
class DayLog:
    day: int
    lots: list[LotState]          # n, tau, lot_id per live lot
    sales_total: int
    waste_total: int
    arrivals: int
    order_qty: int
    demand: int
    L: int
    # M2.5 rich emit:
    sales_by_lot: dict[int, int]  # lot_id -> units sold this day
    waste_by_lot: dict[int, int]  # lot_id -> units wasted this day
    age_at_receipt: float | None  # tau_in of today's delivery, else None
    pack_date: date | None        # ASN/pack date if available, else None

def run_episode(...) -> EpisodeLog: ...  # same CRN streams; richer DayLog rows
```
