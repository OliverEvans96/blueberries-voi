# T-090 Belief charts — age×count rebin + age marginal

## Context

T-054’s `beliefGridFromFlat` still maps lot index to the age axis, so the Belief
heatmap disagrees with its Age×Count labels and with truth markers at `(tau, n)`.
This ticket fixes presentation rebinning and adds a merged age-marginal strip without
changing the Python FlatBelief wire.

## Acceptance criteria

- [ ] Given a FlatBelief with `L ≈ 2` and `tau_grid` spanning roughly `0..8`, after
      `beliefGridFromFlat` the Belief heatmap’s x-domain (from `tau_edges`) is age in
      days on that span — **not** `[0, L]`.
- [ ] `BeliefGrid.density` is shaped **`K × C`** (age bins × count bins);
      `tau_edges === centersToEdges(tau_grid)` (length `K + 1`); `count_edges` is
      integer-friendly from `0` through `max(n_l, truth n, 1)` (length `C + 1`).
- [ ] Rebin deposits each lot’s mass
      `mass[k] = lot_counts[l] * age_marginals[l*K+k]` into the count bin for that lot’s
      `n_l` (nearest-integer bin when `n_l` is non-integer).
- [ ] Merged age marginal `m` has length `K` with
      `m[k] = Σ_l lot_counts[l] * age_marginals[l*K+k]`; when each lot’s age row
      normalizes to 1, `Σ_k m[k]` equals `Σ_l lot_counts[l]` (within float tolerance).
- [ ] Age-marginal chart x-domain matches the heatmap `tau_edges` domain (shared age
      axis); it mounts as a **top** marginal above the Belief heatmap.
- [ ] Truth overlay markers remain at `(lot.tau, lot.n)` and land on the same age×count
      scales as the rebinned cells (no lot-index x placement).
- [ ] Belief section `plotIds` include both the age-marginal plot id and the heatmap plot
      id; section blurb mentions age×count belief vs truth (and the age marginal).
- [ ] No Python / wire FlatBelief shape change: `age_marginals` stays length `L*K`;
      adapters and Python export tests for flat length remain green without schema edits.
- [ ] Vitest covers projector rebin (`K×C`, edges, deposit) and age-marginal vector;
      existing `densityFromFlatBelief` / `beliefGridFromFlat` tests that asserted **`L×K`
      lot-index axes** are updated or replaced in this ticket (T-054 debt supersession).
